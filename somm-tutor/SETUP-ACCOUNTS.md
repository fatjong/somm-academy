# 帳號系統設定（Firebase）

學生註冊、信箱驗證、登入、忘記密碼都由 Firebase Authentication 處理。
免費方案即可，不需要綁信用卡，也不需要自己架伺服器。整個設定約 15 分鐘，只需做一次。

Firebase 主控台的畫面偶爾會改版，按鈕位置若和下面描述略有不同，找同名的功能即可。

## 一、建立專案

1. 用 Google 帳號登入 https://console.firebase.google.com
2. 按「建立專案」，名稱例如 `lhu-somm-tutor`
3. Google Analytics 可以關閉，按建立

## 二、取得網站設定值

1. 專案首頁按「新增應用程式」，選網頁圖示 `</>`
2. 暱稱隨意填，例如 `somm-tutor`，**不用**勾選 Firebase Hosting，按註冊
3. 畫面會出現一段 `const firebaseConfig = { ... }`
4. 把 `firebase-config.example.js` 複製一份，改名為 **`firebase-config.js`**
5. 用這段設定的值，取代檔案裡對應的 `apiKey`、`authDomain`、`projectId` 等欄位

之後要再找這段設定：齒輪 → 專案設定 → 一般 → 往下捲到「你的應用程式」。

## 三、開啟電子郵件登入

1. 左側選單「建構 → Authentication」，按「開始使用」
2. 「登入方式」分頁 → 選「電子郵件/密碼」→ 開啟第一個開關 → 儲存
   （第二個「電子郵件連結」不用開）

## 四、加入授權網域

1. Authentication →「設定」分頁 →「授權網域」
2. 按「新增網域」，輸入 `fatjong.github.io`

少了這一步，驗證信與重設密碼信裡的連結無法帶學生回到網站。

## 五、建立資料庫（存放學號、姓名、生日）

1. 左側選單「建構 → Firestore Database」→「建立資料庫」
2. 位置選 **`asia-east1`（台灣）**，這個之後不能改
3. 選「以正式版模式啟動」
4. 建好後到「規則」分頁，把整段內容換成 `firestore.rules` 檔案裡的內容，按「發布」

規則的重點：

- 學生只能讀寫**自己的**資料與問答紀錄，看不到別人的，也不能刪除雲端的問答紀錄
- 列在 `isAdmin()` 清單裡的**老師帳號**，可以讀取、刪除全班的問答紀錄
- 清單目前是 `fatjong@gmail.com`。要讓其他老師也能查看，把他的信箱加進清單，例如：

```
request.auth.token.email in [
  'fatjong@gmail.com',
  'mhsieh@gm.lhu.edu.tw'
];
```

老師也要先在網站上**註冊並完成信箱驗證**，用那個帳號登入網站後，教師模式的「問答紀錄」分頁才讀得到資料。

## 六、（建議）調整寄出的信

Authentication →「範本」分頁，可以修改驗證信與重設密碼信的寄件者名稱，
例如改成「AI侍酒師問答庫」。網站已把語言設為繁體中文。

## 七、上傳並測試

1. 把 `index.html` 和 `firebase-config.js` 一起推上 GitHub
2. 用手機或無痕視窗開啟網站，走一次：註冊 → 收驗證信 → 點連結 → 回網站按「我已完成驗證」→ 進入問答
3. 登出後試一次「忘記密碼」

驗證信找不到時，請先看垃圾郵件匣。學校信箱有時會擋 Firebase 的信，可以請學生改用常用的個人信箱。

## 教師密碼放在哪裡

教師密碼**只存在 Firebase 主控台的資料庫規則裡**。網頁原始碼、GitHub 上的任何檔案（包含這份說明與 README）都沒有教師密碼，也沒有它的雜湊值，學生看原始碼讀不出來。
老師輸入教師密碼時，網頁把它送到 Firebase，由規則比對，對了才開啟教師模式。

**設定或更換教師密碼**（第一次使用時做，之後要換密碼時也照做）：

1. Firebase 主控台 → 建構 → Authentication →「登入方式」→ 新增供應商 →「匿名」→ 啟用 → 儲存（只需做一次）
2. Firestore Database →「規則」分頁，把整段換成 `firestore.rules` 的內容
3. 找到 `teacherKey()`，把引號裡的「請在這裡填入教師密碼」換成你要的教師密碼
4. 按「發布」，約一分鐘後生效

注意：

- 只在主控台裡填密碼。**不要把填了密碼的 `firestore.rules` 上傳到 GitHub**；repo 裡放的這份保持「請在這裡填入教師密碼」即可（也可以不上傳）
- 舊版網頁曾在原始碼放過密碼的雜湊值，GitHub 的歷史紀錄裡還查得到，**請換一組新的教師密碼**，只填在主控台
- 建議至少 8 個字元、混合英數，不要用生日或電話
- 規則讓每次教師登入的權限最多維持 8 小時；離開教師模式時網頁會自動登出

## 老師如何查看學生的問答紀錄

首頁按「教師登入」→ 輸入教師密碼 →「問答紀錄」分頁。點學生、再點對話，就能看到當時的完整畫面。
對話上方可以「下載這段對話」「刪除這段對話」；學生名稱旁有「下載此學生紀錄」；最上方有「下載全部紀錄」（CSV，Excel 可直接開啟）。
刪除類的操作會永久刪除雲端資料，需要再輸入一次教師密碼。

學生側欄的「清空紀錄」只會清除該裝置上的列表，雲端紀錄仍保留，也需要教師密碼。

## 老師如何管理學生帳號

- **帳號列表、停用、刪除、重設密碼**：Firebase 主控台 → Authentication →「使用者」分頁。
  每一列右側的選單可以停用或刪除帳號，也能直接寄重設密碼信。
- **學號、姓名、生日**：Firestore Database →「資料」分頁 → `users` 集合，每份文件是一位學生。

## 常見問題

**網站顯示「帳號系統尚未設定」**
`firebase-config.js` 不存在、檔名打錯，或裡面還是範本的「請填入」。確認它和 `index.html` 在同一層。

**註冊時出現「尚未開啟電子郵件／密碼登入方式」**
第三步沒有完成。

**apiKey 放在網頁裡安全嗎？**
可以。Firebase 的 apiKey 只是專案識別碼，不是密碼。真正的保護是第四步的授權網域，
以及第五步的資料庫規則。若想更保險，可到 Google Cloud 主控台的「API 和服務 → 憑證」，
把這把金鑰限制為只能從 `https://fatjong.github.io/*` 使用。

**個人資料**
學生的學號、姓名、生日會存在 Firestore。依學校個資規範，請在課程說明中告知學生
蒐集的項目與用途。
