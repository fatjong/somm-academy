# AI 侍酒師學習助理

龍華科技大學觀光休閒系「葡萄酒賞析與服務」課程用。指導教師：謝美婷。

純前端，不需要伺服器、資料庫或任何金鑰。放上任何 HTTPS 空間即可運作。

## 檔案

```
index.html          主程式（校徽已內嵌）
kb/manifest.json    教材清單
kb/service.md       範例教材：侍酒服務流程
kb/pairing.md       範例教材：餐酒搭配原則
.nojekyll           避免 GitHub Pages 處理掉特殊檔名
```

## 部署到 GitHub Pages

1. 建一個 repo，把本資料夾的**內容**（不是資料夾本身）推到 `main` 分支根目錄
2. Settings → Pages → Source 選 `Deploy from a branch`
3. Branch 選 `main`、資料夾選 `/ (root)`，Save
4. 等一兩分鐘，網址為 `https://<帳號>.github.io/<repo>/`

必須用 HTTPS 開啟，語音輸入才會運作。直接用 `file://` 開啟本機檔案會讓 `kb/` 載入失敗。

## 新增教材

把 Markdown 檔放進 `kb/`，再到 `kb/manifest.json` 加一行：

```json
{ "files": [
  { "file": "service.md", "name": "侍酒服務流程講義" },
  { "file": "week5.md",   "name": "葡萄酒賞析與服務 Week 5" }
] }
```

`name` 是引用時顯示的教材名稱。

### Markdown 寫法

`#` 到 `####` 的標題會成為章節名稱，引用時顯示為出處。標題之間的段落各自成為可被檢索的片段。

```markdown
# 醒酒

## 醒酒的目的

醒酒有兩個目的。第一是讓酒液接觸空氣……

第二是分離陳年紅酒瓶底的沉澱物……
```

一段寫一個完整概念，效果最好。段落太短（少於八個字）會被略過。

## 教師模式

登入頁右下角「教師登入」，預設密碼 `620620`。

可以查看學生問到但教材沒有涵蓋的問題，直接寫答案加入知識庫，或上傳補充教材。教師在後台加入的內容存在瀏覽器裡，換裝置看不到；要長期保存請寫成 Markdown 放進 `kb/`。

### 更換密碼

密碼在原始碼中以 SHA-256 雜湊儲存，搜尋不到明碼。要更換，先算出新的雜湊值：

```bash
echo -n "somm-lhu-2026:新密碼" | shasum -a 256
```

把 `index.html` 裡 `PW_HASH` 的值換成結果即可。

**這是純前端驗證，安全性有限。** 瀏覽器要能判斷密碼對錯，依據就必須在瀏覽器裡，因此雜湊值可被取出離線破解。純數字密碼尤其脆弱。建議改用十碼以上並混合字母。若日後要在後台存放學生成績或個資，必須改為伺服器端驗證。

## 語音

使用瀏覽器內建語音合成，會自動選用系統中的 HsiaoChen（曉臻）。電腦版預設音調 1.22、語速 1.02，行動裝置 1.00 / 1.10，句與句之間加入微幅起伏避免機械感。

學生電腦若未安裝中文語音，會退回其他語音，發音會不正確。Windows 可在「設定 → 時間與語言 → 語音 → 管理語音」新增「中文（繁體，台灣）」。

語音輸入使用 Web Speech API，Chrome 與 Edge 支援，Firefox 不支援，且必須在 HTTPS 下才能使用。

## 目前的限制

**檢索是字元比對，不是語意理解。** 問法與教材用字差太多會找不到，例如教材寫「收斂感」而學生問「太澀」可能漏掉。改善方式是在教材中多寫幾種同義說法。

**回答是教材原文摘錄，不是模型整理過的內容。** 純前端無法呼叫語言模型。這也表示引用一定真實，不可能出現捏造的出處。

**教材公開可讀。** GitHub Pages 上的 `kb/` 任何人都能直接下載。有版權疑慮的講義請勿放入。

**資料存在瀏覽器。** 學生的提問紀錄與教師後台的補充內容都存在各自的裝置上，沒有跨裝置同步，也沒有多使用者隔離。

以上限制要解除都需要後端。

## 預錄語音（讓聲音變好聽的關鍵）

瀏覽器內建語音的音質有限，機械感明顯。要得到 Azure zh-TW-HsiaoChenNeural
那種自然的聲音，做法是**先在自己電腦上把固定句子合成成音檔**，放進
`voice/` 資料夾。網頁會自動偵測並優先使用，找不到才退回瀏覽器語音。

網站本身仍然是純前端，不需要伺服器或金鑰。

### 產生步驟

```bash
pip install edge-tts
python make-voice.py
```

會讀 `voice-lines.json`，輸出 `voice/*.mp3` 與 `voice/manifest.json`。
把 `voice/` 資料夾和 `index.html` 一起推上去即可。

改句子就編輯 `voice-lines.json`，再重跑一次（已存在的會略過，加 `--force`
可全部重做）。想調語氣：

```bash
python make-voice.py --rate="-4%" --pitch="+10Hz"
```

### 哪些句子有預錄

歡迎詞、查不到資料的拒答、範圍外的婉拒、六個推薦問題的答案。這些涵蓋了
學生實際聽到的大部分內容。

**依教材即時生成的答案無法預錄**，那部分仍會用瀏覽器語音，聽起來會和
預錄段落有落差。這是純前端架構的固有限制：要讓任意文字都有相同音質，
必須有後端即時呼叫雲端 TTS。

### 路徑

網頁會依序尋找 `voice/`、`../voice/`，副檔名先試 `.ogg` 再試 `.mp3`。
若部署在子目錄而語音檔放在上層，也能找到。

用 `?voice` 參數開啟網頁，左下角會顯示是否找到預錄包。
