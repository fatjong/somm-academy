# AI侍酒師問答庫

龍華科技大學觀光休閒系「葡萄酒賞析與服務」課程用。任課老師：謝美婷。

純前端，不需要伺服器或金鑰。放上任何 HTTPS 空間即可運作。

## 檔案

```
index.html          主程式（校徽已內嵌）
kb/manifest.json    教材清單
kb/quiz.json        測驗題庫（500 題）
kb/*.md             課程教材
```

## 測驗

學生按「AI 測驗我」，系統從 `kb/quiz.json` 隨機出 10 題，依基礎 4 題、進階 4 題、挑戰 2 題的順序由淺入深。
測驗時會朗讀題目與選項，作答後朗讀結果與教材原句，右上角可關閉語音。每答一題立刻公布對錯、顯示教材原句與出處，結束後給總分與答錯清單。
成績依登入的 email 存在**該裝置的瀏覽器**，教師模式「學習紀錄」分頁可看到這台裝置的紀錄並匯出 CSV。

題庫是從 kb/ 教材自動產生的克漏字與是非題，**建議上線前抽查幾題**。
要修改就直接編輯 `kb/quiz.json`：`q` 題目、`o` 選項、`a` 正確選項的序號（從 0 起算）、
`e` 教材原句、`f` 來源檔名、`l` 難度（1 到 3）。

## 歷史對話

左側列表會列出這個帳號在這台裝置的對話，點一下可以載回整段問答，引用的教材也能繼續點開。
按 × 只從列表移除。換裝置看不到。

## 跨裝置的限制

每位學生的對話與成績都存在自己的瀏覽器，老師的裝置讀不到，也沒有真正的帳號系統
（登入頁目前不驗證帳號密碼）。要做到全班成績集中管理、教師查看學生對話、帳號管理，
必須加上後端。

## 教材

把 `.md` 放進 `kb/` 並更新 `kb/manifest.json`。教師模式可一鍵匯出 manifest。

GitHub Pages 預設用 Jekyll 處理網站，帶 YAML 檔頭的 `.md` 會被轉成網頁而讀不到；
網頁已內建備援，會改從 raw.githubusercontent.com 讀原始檔。想讓網站直接提供，
在 repo 根目錄建立一個空的 `.nojekyll` 檔案。
