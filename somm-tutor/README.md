# AI侍酒師問答庫

龍華科技大學觀光休閒系「葡萄酒賞析與服務」課程用。任課老師：謝美婷。

網站本身是純前端，放上任何 HTTPS 空間即可運作；帳號系統使用 Firebase 免費方案。

## 檔案

```
index.html                  主程式（校徽已內嵌）
firebase-config.js          帳號系統設定（已填入專案 ai-sommeliers-tutor）
firebase-config.example.js  設定範本，換專案時使用
SETUP-ACCOUNTS.md           帳號系統設定步驟
firestore.rules             資料庫權限規則，貼到 Firestore「規則」分頁
kb/manifest.json            教材清單
kb/quiz.json                測驗題庫（157 題）
kb/*.md                     課程教材
```

## 帳號

學生需先註冊（學號、姓名、玩家帳號、電子郵件、生日年月、密碼），完成信箱驗證後才能登入。
登入頁有「忘記密碼」，會寄重設密碼信。學生介面右上角可登出；教師模式有「回首頁」。

第一次使用前要完成 Firebase 設定，步驟見 `SETUP-ACCOUNTS.md`。
沒有設定時，登入頁會顯示提示，並只提供訪客試用。

更新網站時只替換 `index.html` 與 `kb/`，**不要覆蓋已填好的 `firebase-config.js`**。

## 日常對話與學習引導

「你好」「你是誰」「你會什麼」「你有哪些資料」「資料的時間」「我應該怎麼使用」「教教我」「考考我」「謝謝」「再見」這類問題，
不查教材、也不會記成待回答問題，直接由內建回覆處理，回答後附上可以點的建議問題。

- 「你有哪些資料」依目前載入的教材自動統計份數並分類
- 「資料的時間」讀 GitHub 上 `kb/` 最後一次提交的日期，讀不到時改用網站檔案的修改時間
- 「教教我」列出六步學習路線：侍酒師的工作 → 葡萄品種 → 品飲與香氣 → 產區 → 餐酒搭配 → 侍酒服務流程。
  每一步的問題答完，會接著提示下一步與「AI 測驗我」
- 「你可以教我醒酒嗎」「請問什麼是單寧」這類問法，會先去掉客套的開頭結尾，再拿主題去查教材

要修改這些回覆或學習路線，在 `index.html` 搜尋 `var PATH=` 與 `function talkReply`。

## 測驗

學生按「AI 測驗我」，系統從 `kb/quiz.json`（157 題）隨機出 10 題，依基礎 4 題、進階 4 題、挑戰 2 題的順序由淺入深。
測驗時會朗讀題目與選項，作答後朗讀結果與教材原句，右上角可關閉語音。每答一題立刻公布對錯、顯示教材原句與出處，結束後給總分與答錯清單。
成績依登入的 email 存在**該裝置的瀏覽器**，教師模式「學習紀錄」分頁可看到這台裝置的紀錄並匯出 CSV，也能刪除單筆、清除單一帳號或清空全部（需教師密碼）。

題庫依教材逐題撰寫：題目資訊完整、只有一個正確答案，出處原句逐字取自教材，並以程式驗證每題都能定位回正確段落。
要修改就直接編輯 `kb/quiz.json`：`q` 題目、`o` 選項、`a` 正確選項的序號（從 0 起算）、
`e` 作答後顯示的解說、`k` 用來定位段落的教材原句（沒有就用 `e`）、`f` 來源檔名（不含 .md）、`l` 難度（1 到 3）、`t` 題型（mc 選擇、tf 是非）。

## 歷史對話與問答紀錄

登入後，自己的發言與右上角都以玩家帳號（例如 A1234567890胖賢毅）顯示。
左側列表是這台裝置上的對話，點一下可以載回整段問答，引用的教材也能繼續點開；按 × 只從列表移除。
側欄「清空紀錄」會清除這台裝置的列表，需要教師密碼。

每一段問答同時保存在雲端（Firestore）。輸入教師密碼後，網站會自動以老師帳號連線（第一次使用的設定見 SETUP-ACCOUNTS.md），在教師模式「問答紀錄」分頁
可以依學生查詢完整的對話畫面，也能刪除單一對話、清空單一學生或全部紀錄（需教師密碼）。
紀錄可以下載成 CSV（Excel 可直接開啟）：這段對話、此學生、或全部學生，每一列是一組提問與回答。

學生登入後問的問題才會進雲端；若寫入失敗，學生畫面會跳出提示，請學生告知老師。

## 跨裝置的限制

帳號與問答紀錄都在雲端，老師可以集中查詢。測驗成績目前仍存在各自裝置的瀏覽器，下一步可以同樣存進 Firestore。
教師模式的密碼是網頁內驗證；真正的雲端資料權限由 Firestore 規則的管理者清單決定。

## 教材

把 `.md` 放進 `kb/` 並更新 `kb/manifest.json`。教師模式可一鍵匯出 manifest。

GitHub Pages 預設用 Jekyll 處理網站，帶 YAML 檔頭的 `.md` 會被轉成網頁而讀不到；
網頁已內建備援，會改從 raw.githubusercontent.com 讀原始檔。想讓網站直接提供，
在 repo 根目錄建立一個空的 `.nojekyll` 檔案。
