# 侍酒師的服務範疇

侍酒師的服務範疇廣泛，涵蓋了從餐前準備、酒款介紹到實際服務的每一個環節，旨在為顧客提供極致的品酒體驗。這不僅包括對酒本身的知識，更延伸至相關器具的選擇、使用與維護，以及侍酒師自身的專業形象和溝通技巧。

**一、 開瓶器**

開瓶器是侍酒師不可或缺的良伴，其發展歷經刀具、T型螺旋鑽子，至今已有多樣化的種類。

* **T字開瓶器**：這是最原始且簡單的類型，需將螺旋鑽子轉入瓶塞再用力拔出。其優點是價格便宜，但若施力不均，可能導致軟木塞斷裂或碎裂。
* **侍酒刀**：外型類似鸚鵡，又稱海馬開瓶器（The Waiter's Friend），是侍酒師最常用的開瓶器。它由鋁箔刀、支撐架、握把和螺旋鑽子四部分組成。依支撐架形式，可分為一段式或兩段式，其中兩段式因有兩個支點而較好施力。
* **槓桿式開瓶器**：此類開瓶器呈雙臂造型，也稱蝶型開瓶器。其操作方式是將螺旋鑽子轉入瓶塞後，壓下兩邊手把即可拉起瓶塞，但較少為專業侍酒師使用。
* **旋轉開瓶器（Screwpull）**：這款開瓶器的螺旋鑽子較長，只要持續轉動，瓶塞會自動旋上來，特別適用於開啟較脆弱的瓶塞。
* **半自動式開瓶器**：又稱兔耳朵開瓶器，適合大量開酒時使用。操作時，夾住酒瓶口並壓下把手直至聽到「卡」一聲，再向上提把手即可輕鬆拔起軟木塞。然而，它不適合脆弱的軟木塞，且價格昂貴。
* **老酒開瓶器（Ah-So 開瓶器）**：專為老酒設計，利用兩片特殊鋼材夾住脆弱的軟木塞，再一邊轉動一邊將軟木塞夾出。
* **電動開瓶器**：原理與旋轉開瓶器相似，透過電動方式將螺旋鑽子鑽入瓶塞，完全不需費力。
* **氣壓式開瓶器**：透過一根打氣針插入瓶中，打氣進入後利用氣壓原理將瓶塞擠出。

**二、 酒杯**

酒杯對於品嘗葡萄酒的色、香、味至關重要，它不僅是容器，更是讓酒的風味充分發揮的關鍵器具。若酒杯選擇不當，酒的美味和特色將無法突顯。

* **酒杯的基本特徵**：
  + 葡萄酒杯通常是**透明無色、杯身薄而平滑的鬱金香形高腳玻璃杯**。
  + 由上至下可分為：杯口、杯身、杯腳、杯底。
  + 使用時通常拿**杯腳或杯底**，碰杯時主要碰杯身，應避免碰觸杯口以防破裂。
  + **透光度佳，便於觀察色澤**：杯子的透光度非常重要，杯身有刻花或顏色會影響透光度和酒汁顏色，材質和厚薄也有影響。
  + **便於搖杯**：葡萄酒需要與空氣接觸以釋放香氣，因此酒杯造型需提供足夠的空間讓酒液流動，方便搖杯。
  + **高腳造型，避免手溫影響**：高腳設計可以避免手溫影響酒的適飲溫度，同時也避免指紋沾染杯身，影響透光度。
* **酒杯的材質**：
  + **水晶杯**：多數人偏好水晶杯。傳統水晶杯含有氧化鉛，其熔點低、抗化學性差，在濕度與酸鹼度影響下容易釋放鉛，長期使用可能對人體有影響，因此受到食品安全法令限制，出廠需通過檢驗。許多酒杯廠商已開始生產**無鉛水晶杯**。
  + **一般玻璃杯**：相較於水晶杯，一般玻璃製成的酒杯無法達到輕薄閃亮的程度，但價格較為平易近人，且不易破裂。
* **常見的葡萄酒杯型**：
  + **國際標準品酒杯（ISO 杯）**：由1974年法國國家產地命名委員會（INAO）設計，廣泛應用於品酒活動中。這是一種**全能型酒杯**，不論紅酒、白酒、氣泡酒、波特酒、雪利酒、白蘭地或威士忌等烈酒，都可使用ISO杯品嘗。其標準規格為杯腳5-6公分，容量約215毫升，杯口小而杯腹大，杯體最寬處直徑65公釐，杯口直徑46公釐。倒酒至最寬腹部時約為50毫升。
  + **紅酒杯**：紅酒需要與空氣有較多接觸，因此杯口通常較廣。主要分為波爾多杯和勃根地杯。
    - **波爾多杯**：適合單寧和果酸較重的酒。其杯身修長呈鬱金香形，使酒汁較慢接觸口腔；杯口較寬，便於聞到波爾多酒豐富的香氣變化；尺寸較大，能避免搖杯時酒液灑出。
    - **勃根地杯**：杯腹寬大如球形，杯口收窄，有助於凝聚香氣，適合香氣內斂柔和的勃根地紅酒。
  + **白酒杯**：通常呈現U形，比紅酒杯小，容量約為紅酒杯的一半，有助於避免香氣揮發過快，並維持低溫狀態。粉紅葡萄酒也適合使用。
  + **香檳杯**：專為氣泡酒設計，杯身纖細，讓氣泡有足夠的上升空間。杯口窄小，有助於香氣更集中持久。

**三、 醒酒器**

將葡萄酒從原瓶倒入醒酒器中，可以讓酒體充分接觸空氣，達到快速醒酒的效果，同時也能去除酒中的沉澱物。

* **歷史與演變**：醒酒器早期由陶器、銅器、銀器製成，文藝復興時期開始出現彩色玻璃器皿的醒酒器。
* **設計特點**：體型多為下半身穩重寬厚，細長的瓶頸，可增加葡萄酒與空氣的接觸面積。隨著玻璃工藝和製造技術的進步，醒酒器也成為賞心悅目的擺飾品。
* **功能分類**：根據功能可分為一般醒酒器、老酒醒酒器和白酒醒酒器。通常年輕的白酒很少需要醒酒。
* **現代醒酒器**：醒酒器造型多變，有的形狀像實驗室試瓶的變形，有的像斜放的酒瓶，甚至附有把手方便注酒。一些醒酒器還可搭配濾器篩網來過濾雜質，並在倒酒時保持穩定。隨著科技進步，還有**電子醒酒器和快速醒酒器**，這些利用氣壓或空氣力學原理將空氣打入酒中，使酒快速與空氣接觸，多為業餘紅酒愛好者使用。

**四、 侍酒師的儀態、表達與解說**

侍酒師的專業形象和溝通能力對於提供優質服務至關重要。

* **儀態與服裝**：
  + 侍酒師的服裝依餐廳規定或特色而異，但通常比一般服務生正式，多會穿著外套，衣領上別有識別胸章。
  + 正式餐廳的侍酒師會穿著伊頓短外衣，圍圍裙，並戴上領結。較休閒的餐廳則可能以西裝背心代替外套。
  + 無論穿著何種服裝，侍酒師的儀容都需**整齊清潔**，注意飲食安全衛生，頭髮梳理妥當。
* **表達與解說**：
  + 侍酒師必須推薦和解說葡萄酒等飲品，因此**口語表達**非常重要。
  + 態度要**落落大方**，講話音量要足夠，咬字清晰，目光需環視所有客人，而非僅對主客一人。
  + 需善於察言觀色，從客人的表情判斷自己的解說是否足夠，並與客人建立良好的互動。
  + 上酒時，應先**念出酒名**，並逐一介紹酒的相關資訊，如釀製的葡萄品種、酒莊、產區、國別和年份。是否進一步講解，可視客人反應而定，避免像背書般機械性地說給客人聽。

**五、 侍酒準備與服務注意事項**

精心的準備和細膩的服務是侍酒成功的基礎。

* **備妥侍酒器具**：
  + 侍酒師應隨身攜帶侍酒刀和打火機。
  + 依餐廳和場合不同，會設置備品桌或儲放侍酒相關器具的場所，其中應包含：
    - 各式葡萄酒杯、水杯和試酒杯。
    - 服務巾（用於擦拭或墊酒瓶）。
    - 餐巾紙（用於擦拭瓶口和墊軟木塞小碟）。
    - 小碟子（放置軟木塞）。
    - 試酒杯（供侍酒師試酒）。
    - 換瓶用品（醒酒器、蠟燭與燭台）。
    - 冰桶（用於氣泡酒或白酒保冷）。
    - 托盤。
* **挑選和檢查杯具**：
  + 侍酒師需依客人所點酒款，挑選適合的酒杯。
  + **挑選正確的杯具**: 侍酒師應依客人所點酒款，**挑選適合的酒杯**。例如，紅酒杯通常杯口較廣，分為波爾多杯（適合單寧和果酸較重的酒）和勃根地杯（杯腹寬大如球形，適合香氣內斂柔和的酒）；白酒杯較紅酒杯小，容量約一半，以維持低溫並避免香氣快速揮發；香檳杯則纖細，便於氣泡上升並集中香氣
  + 將杯具拿到客人面前前，務必檢查是否**乾淨、無破損、無汙點、無異味**。
* **服務動線**：
  + 服務時應站在客人**右側略偏後方**。
  + 為客人擺放酒杯、遞送軟木塞給主客、請客人試酒時，一律沿**順時鐘方向**進行，不可折返。
  + 擺放酒杯和斟酒時，應**先服務女性客人，再為男性客人服務**，同樣以順時鐘方向進行，不可折返。
* **擺杯**：
  + 酒杯通常擺在客人的水杯上方，香檳杯除外。
  + 持杯時應以大拇指和食指抓住杯腳，使水杯與酒杯杯腳的距離約為手掌虎口的寬度。
* **點酒確認展示酒瓶**：
  + 開酒前，用服務巾輕拭瓶身，服務巾墊在酒瓶後側和瓶底，露出酒的正標。
  + 將酒拿到桌邊請主客確認並介紹酒款向賓客展示酒標，確認釀製的葡萄品種、酒莊、產區、國別和年份。
  + 介紹結束後將酒拿回服務桌，無論開瓶前或換瓶後，酒瓶在服務桌上都不可直接放在桌上，必須**墊服務巾，且酒標面向客人**。
* **開瓶**：
  + 開酒時，酒瓶底部不能離開桌面，螺旋鑽子也不能刺穿軟木塞。
  + 取下軟木塞確認味道和試酒時，侍酒師都需**側身對著客人**。
  + 擦拭瓶口的餐巾紙和取下的鋁箔封籤，都應放在**衣服口袋中，不可放在桌面**。
  + 收軟木塞時，需徵求客人同意，因為有些客人有收集軟木塞的嗜好。
  + 開氣泡酒時，應**轉動瓶身而非轉動瓶塞**，且不可發出太大聲音，應是緩緩釋放氣體，一般稱作「少女的嘆息聲」，並隨時注意瓶中氣體暴衝狀況。
* **換瓶（醒酒）**：
  + 紅酒換瓶前點燃蠟燭時，點火和熄火都需轉身，避免火的煙擴散室內影響用餐環境。用畢都應收入口袋。
  + 換瓶時可握醒酒器的瓶頸或底部，**平穩穩定地將酒倒入醒酒器**，避免酒液濺出。
  + 酒瓶與醒酒器瓶口不能碰撞。
  + 將瓶頸處放置在與眼睛、燭火中心點成一直線的位置，以便觀察瓶底是否有殘渣，若有沉澱物，則不可再繼續倒酒。
  + 醒酒瓶也不能直接放在桌上，需墊服務巾。
* **保冷**：
  + 白酒和氣泡酒需使用冰桶保冷。
  + 冰桶內應放入冰塊和水，約七分滿，使其可浸至酒瓶瓶頸處。
  + 冰桶應蓋上服務巾，取出酒瓶時以服務巾擦拭瓶身避免滴水，倒完酒後放回冰桶並蓋上服務巾。
* **斟酒服務**：遵循「**倒、停、轉、收**」的口訣。
  + 倒酒不可將酒滴出杯外，倒完後瓶口應微向上仰起，輕輕轉動可避免酒液滴出。
  + 倒酒時，瓶口不得碰觸杯口，距離杯口約3-5公分。
  + 侍酒師須緊盯服務標的物，不可將酒杯拿起來倒酒。
  + 倒入酒量高度應一致，**紅白酒約至杯子1/3處，氣泡酒則至1/2處**。
  + 每次倒完酒後，一定要擦拭醒酒器瓶口或酒瓶瓶口外側。
* **酒質有異時的處理原則**：
  + 若開瓶後從軟木塞或試酒時，侍酒師發現酒質有異，應先請**第二位侍酒師進行確認**。若確認無誤，可請主客試酒；若兩位侍酒師都認為酒質有異，可直接更換一瓶，但應先告知客人。
  + 若侍酒師確認酒沒有問題，但主客認為味道不對，可徵詢客人同意後，請第二位侍酒師確認。若確認無誤，可請主客形容味道，或說明原因，設法改進。例如，香氣不足可藉由較長時間醒酒改善；溫度太低可換瓶升溫；溫度太高則可浸冰水略降溫。
  + 設法改進後，若客人仍認為味道不對，則應**直接更換一瓶酒**服務。

**六、 酒的服務溫度**

酒精飲品有其適飲溫度，侍酒師的任務之一，就是讓客人在適飲溫度下充分品嘗酒品的美味。溫度對葡萄酒尤其重要，因為它會直接影響酒的香氣和口感。

* **低溫影響**：低溫會壓抑風味的表現，使酸度上升，從而帶來清爽感。因此，口味偏甜的酒通常會冰鎮在較低的溫度下飲用，以達到口感的平衡。
* **高溫影響**：高溫會使酒液中的酒精與香氣成分快速揮發，導致香氣消散。造成酒精感突出、口感失衡。
* 紅酒

| **酒體類型** | **建議溫度範圍** |
| --- | --- |
| 酒體飽滿 | 17°C ~ 18°C |
| 酒體中等至輕盈 | 14°C ~ 16°C |
| 果味紅酒 | 12°C ~ 13°C |

* 白酒

| **酒體類型** | **建議溫度範圍** |
| --- | --- |
| 酒體飽滿 | 11°C ~ 13°C |
| 酒體輕盈 | 9°C ~ 10°C |

* 粉紅酒：建議溫度：9°C ~ 12°C
* 氣泡酒與甜酒

| **酒類型** | **建議溫度範圍** |
| --- | --- |
| 香檳、卡瓦 | 4°C ~ 7°C |
| 莫思卡托、冰酒 | 6°C ~ 8°C |

小提醒：亞洲的「室溫」常高於歐洲標準（16°C ~ 20°C），所以紅酒不建議直接在室溫下飲用。

**葡萄酒歷史**

葡萄酒的歷史起源於約西元前2000年的希臘，隨著羅馬帝國的擴張，葡萄酒文化傳播至中歐各地 。羅馬帝國滅亡後，葡萄酒的發展轉由教會主導，教會將其視為「基督的聖血」，釀酒成為教會的重要工作 。18世紀，隨著玻璃瓶與軟木塞的普及，葡萄酒逐漸成為重要的貿易商品 。19世紀，葡萄根瘤蚜蟲病幾乎摧毀了歐洲所有葡萄樹，但透過嫁接美國葡萄樹的方式得以復興，這場災害也間接提升了釀酒技術 。同一時期，法國細菌學家巴斯德發現了酒精發酵原理，讓葡萄酒釀造技術成為一門專業學科 。20世紀二戰後，因商業需求，釀酒技術與種植面積大幅擴展，使生產高品質葡萄酒變得不再困難 。

要釀造有特色的優質葡萄酒，有四大條件：適宜的地理環境（緯度、土壤）、適當的氣候溫度（陽光、溫度、雨水）、優良的葡萄品種，以及釀酒師的技術 。其中，葡萄生長的「風土條件」（Terroir）指的是影響葡萄酒品質的環境與氣候，包括緯度、土壤成分與氣候等 。釀酒葡萄主要種植在北緯35～55度與南緯35～55度的溫帶地區 。

**影響葡萄酒品質的四大條件**

* **適合的地理環境**：緯度、土壤。
* **適當的氣候溫度**：陽光、溫度、雨水。
* **優良的葡萄品種**。
* **釀酒師的人文技術**。

**葡萄生長週期**

葡萄在南北半球的生長週期，以陳列方式呈現：

**1. 休眠期 (Dormancy)**

* **北半球**：11月至3月
* **南半球**：5月至9月
* **特徵**：葡萄樹進入休眠，此時根部持續生長，葉子全部掉落。

**2. 萌芽期 (Budbreak)**

* **北半球**：3月至4月
* **南半球**：9月至10月
* **特徵**：氣溫回升後，葡萄樹開始抽出嫩芽，此階段對霜凍非常敏感。

**3. 開花期 (Flowering)**

* **北半球**：5月至6月
* **南半球**：11月至12月
* **特徵**：葡萄樹開花，果農會整理枝葉以確保花朵能獲得充足的日照。

**4. 結果期 (Setting)**

* **北半球**：6月至7月
* **南半球**：12月至1月
* **特徵**：花朵授粉後開始結出綠色的果實，此時需修剪多餘的幼果。

**5. 轉色期 (Veraison)**

* **北半球**：7月至8月
* **南半球**：1月至2月
* **特徵**：葡萄果實開始變色，糖分上升、酸度下降，進入成熟階段。

**6. 採收期 (Harvest)**

* **北半球**：8月至10月
* **南半球**：2月至4月
* **特徵**：葡萄果實完全成熟後進行採收。

**7. 落葉期 (Leaf Fall)**

* **北半球**：10月至11月
* **南半球**：4月至5月
* **特徵**：葡萄樹葉子開始掉落，準備進入下一個休眠週期。

**主要葡萄品種**

**紅葡萄品種**

* **卡本內．蘇維濃 (Cabernet Sauvignon)**
  + **品種特性**：果實小、皮厚、單寧重、顏色深，有「紅葡萄之王」稱號，適合陳年 。
  + **典型香氣**：年輕時帶黑色莓果香，熟成後有黑醋栗、黑櫻桃、李子等果香，經橡木桶有烘焙、菸草等香氣 。
* **梅洛 (Merlot)**
  + **品種特性**：早熟、產量大、單寧柔和，口感滑順，有「新手酒」之稱 。
  + **典型香氣**：有櫻桃、李子、藍莓等深色莓類水果香，帶薄荷、肉桂等香料味 。
* **黑皮諾 (Pinot Noir)**
  + **品種特性**：體質敏感、對環境要求高，適合寒冷地區，風味優雅、細緻多變 。
  + **典型香氣**：年輕時有花香、櫻桃、覆盆子香氣，熟成後帶有花香、香料和動物性香氣 。
* **希哈 (Syrah/Shiraz)**
  + **品種特性**：適合溫和氣候，酒色深黑，酒香濃郁，單寧含量高，抗氧化性強，適合陳年 。
  + **典型香氣**：年輕時有紫羅蘭和黑色漿果香，熟成後有胡椒、皮革、焦油等成熟香味 。

**白葡萄品種**

* **夏多內 (Chardonnay)**
  + **品種特性**：適應力強、產量高，可塑性強，是少數可在橡木桶陳年的白葡萄品種.
  + **典型香氣**：風味廣泛，從清新的萊姆、柑橘到熱帶水果風味，陳年後有奶油、烤麵包等香氣.
* **麗絲玲 (Riesling)**
  + **品種特性**：適合較低氣溫、生長季長，酸度較高，多釀成低酒精不甜白酒，也可釀成貴腐甜酒.
  + **典型香氣**：帶有梔子花、山茶花等白花香，加上柑橘、蜜桃、杏桃等果香，也帶一絲蜂蜜甜香.
* **白蘇維濃 (Sauvignon Blanc)**
  + **品種特性**：個性明顯、直率，有獨特香氣.
  + **典型香氣**：清新、帶多種植物香氣如青草、蘆筍、青椒，也有柑橘類香氣.
* **榭密雍 (Semillon)**
  + **品種特性**：味道濃郁豐富，可單獨釀酒或與其他葡萄混釀，可釀成不甜白酒和貴腐甜酒.
  + **典型香氣**：從檸檬、青草到成熟的杏桃、梨子等香氣，陳年後會出現杏仁、蜂蜜等風味.

葡萄酒的品嘗與搭配

品飲葡萄酒的技巧與東方以五穀雜糧類釀製為大宗的蒸餾酒不同，西方酒類主要以水果發酵酒為主，品飲時需要充分運用感官，包括視覺、嗅覺、味覺，並加上對餘韻的判別。這種西式葡萄酒品飲技巧主要精神來自於侍酒大師提姆．蓋瑟的「演繹式品飲法」，無論是新手或專家，都可以透過這種方法提升品酒技巧。品酒不同於飲酒，品酒通常需要一次品嘗多種酒款，以正確評估與判斷每款酒，因此品酒時會先吸一口酒在口中漱動，讓酒與空氣混合，感受風味後再將酒吐掉，以保持精準分析。在品酒前，也需考量到每個人的感官差異，侍酒師應客觀陳述酒質，讓消費者依喜好選擇。

**品飲的準備與步驟**是品酒不可或缺的一環。首先，在準備方面，**光線以自然光為佳，或使用白熾燈泡的穩定光源**，並準備白色背景以方便觀察酒的顏色，避免在螢光照明下品酒。酒杯不需昂貴，但須符合標準，無刻紋，材質以水晶或強化鈦為佳，若只能選擇一個，建議使用ISO杯。環境中應確保沒有香水、菸味、大蒜等強烈外來氣味干擾。酒款應保持在適合飲用的溫度，需要醒酒的應先備妥。此外，**搖杯是讓葡萄酒與空氣快速接觸以散發香氣的醒酒動作**，搖晃時應手持杯腳，順時針小幅度旋轉。

品飲的步驟可分為視覺、嗅覺和味覺三個部分。

1. 在**視覺**方面，觀察酒色能透露酒齡、產區、窖藏狀態等許多訊息。需要觀察的要素包括：**清淨度**（如美國酒多濾過而清澈明亮）、**光澤**、**色澤**（酒色是熟成狀況指標，年輕紅酒帶紫色調，老酒轉紅寶石或磚紅色，白酒陳年後從淡黃變金黃，並可判斷健康狀況）、**邊緣顏色的變異**（判別新舊酒依據，中央通常比杯緣深）、**沉澱物或微粒**（常見於白酒或紅酒，可能是酒石酸鹽結晶，可透過冷穩定或加溫溶解）、以及**酒痕**（英文稱legs或tears，觀察酒從杯身滑下的痕跡，可判斷酒精濃度及殘留糖度）。

**2. 嗅覺是品飲葡萄酒的關鍵**，其重要性佔85%，遠高於味覺的15%。嗅覺可辨別超過10萬種氣味，而味覺僅能嘗到甜、酸、苦、鹹、甘五味。嗅覺技巧包括**被動吸入法**（鼻子深入杯中嗅聞）和**主動吸入法**（鼻子和嘴巴同時吸氣，讓香氣輕輕游走）。首先應檢查酒是否有瑕疵，如發霉、木塞味、醋酸味等。接著是辨別香氣，葡萄酒的香氣大致分為十大類，且來源可分為：**葡萄原有的香味、葡萄發酵後產生的氣味（酒香或發酵香），以及陳年後帶有木桶香味的醇香（陳釀香）**。

**3. 味覺**是透過實際品嘗來確認嗅到的氣味並評估葡萄酒結構。品嘗時應確認酸度/乾度（從完全不甜到完全成熟的甜酒）、**酒體**（酒在口中的厚重或輕薄感，可用清爽、柔順或醇厚形容）、**香味確認**（再次確認嗅到的主要果香、次要水果香、礦石味、木頭香氣等）。其他重要的味覺要素包括：**單寧**（源自葡萄皮、籽、梗和橡木桶，適度單寧增加風味、結構與複雜度，並具抗氧化作用）、**酸度**（常見有酒石酸、蘋果酸、乳酸、檸檬酸，能讓香氣清晰，平衡甜苦味，過多則無法飲用）、**酒精度**（口腔後部有微熱或刺激感，低酒精葡萄酒可能缺乏高熱量表現）、**結尾/後韻**（飲畢的回味，悠長餘味表示是好酒）、**平衡感**（葡萄酒所有元素的和諧度）、以及**複雜度**（香氣和味道結合後的變化，提供不同香味和味道令人期待）。最終，透過這些感官體驗進行**研判和結論**，思考酒款來源、產地、品種、年份和等級。

**葡萄酒與食物的搭配**是一門微妙的藝術，能增添用餐氣氛與情趣，達到一加一大於二的效果。餐酒的搭配有多種可能性，取決於其在餐點中的角色：可以是**配角**（簡單清爽，不搶主角鋒頭）、與食物**不相上下**（兩者平衡相輔相成）、或是**主角**（食物單純化，凸顯酒的品質）。

搭配食物與酒有其基本原則。通常是**清爽的酒搭配口味淡的食物，濃郁的酒搭配口味較重的食物**。例如，白酒富含檸檬酸，能去腥，適合搭配海鮮；紅酒富含單寧，能分解油質，去油膩口感，適合搭配肉類。對於辛辣菜色，可選擇偏甜餐酒來中和味道。質感軟嫩的菜餚可搭配較淡、略帶果香或不具個性的白酒；慢火燜燉、味道濃郁的菜餚則可搭配酒體較複雜的紅酒。飲用順序也很重要，應遵循**先喝清爽再喝濃郁、先喝淺齡再喝老齡、先喝不甜再喝甜、先喝白酒再喝紅酒**的原則，並注意酒與調味醬的和諧。

葡萄酒與食物搭配的要點建立在對葡萄酒結構的熟悉和實際嘗試的基礎上。主要考慮以下方面：**品質和複雜性**，特別複雜成熟的葡萄酒最好搭配簡單菜餚，避免相互搶味；**結構（酒體）**，應讓餐酒的酒體結構與食物取得平衡，清淡食物搭配酒體輕的葡萄酒，肥厚食物搭配酒體重的葡萄酒；**濃郁度**，葡萄酒的香氣濃郁度也會影響搭配；**酸度**是配餐中最關鍵的成分，可平衡甜度和脂肪，清新味蕾並有解膩作用；**鹹味**，搭配較鹹食物時，葡萄酒中的甜味或酸味能降低鹹味；**甜度**，甜葡萄酒搭配甜食的難度較高；**單寧和苦味**，富含脂肪、蛋白質的多汁食物可降低單寧帶來的乾澀感，食物中的鹽分則可降低葡萄酒的苦味；**酒精度**，辛辣食物會突顯酒精感，因此低酒精濃度、高酸度、低甜度的葡萄酒適合搭配辛辣食物，可降低刺激性。最後，**「經典式」或「地區式」搭配**（即當地產的葡萄酒與當地菜餚搭配）通常是最安全且符合基本搭配原則的方式。
