# 餐酒服務互動情境

**餐酒服務互動情境：**

不同情境都包含了顧客需求以及標準服務流程轉向推薦，侍酒師在推薦酒款時可依顧客需要從高品質酒、一般佐餐酒到無酒精飲品，以熱情的態度讓每位顧客感到被重視有美好的用餐體驗。只有最適合當下情境的選擇創造體驗，侍酒師服務的不只是酒水，更是一段美好的用餐記憶。互動時要學習**聆聽與提問及建議**、**酒款解釋是否簡潔**、**餐酒搭配邏輯**、**服務儀態**、**危機處理等要素**。

### \*\*情境一：初次約會的驚喜\*\*

\* \*\*情境\*\*：一對年輕男女初次約會，看起來有點緊張。他們點了一份海鮮拼盤和一份香煎鴨胸。

\* \*\*潛在需求\*\*：希望留下好印象，餐酒要得體又不張揚，需要一點話題性。

\* \*\*服務員\*\*：「您好，看到您們點了海鮮和鴨肉，風格很不同。需要我為您們推薦一款能同時搭配這兩道菜，又能增添氣氛的葡萄酒嗎？」

\* \*\*顧客\*\*：「好啊，有什麼建議嗎？（產生興趣）」

\* \*\*服務員\*\*：「我推薦一款來自法國盧瓦爾河谷（Loire Valley）的\*\*黑皮諾（Pinot Noir）\*\*。它的酒體輕盈，單寧柔順，不會壓過海鮮的鮮味；同時又有足夠的果香和酸度，可以解鴨肉的油膩。它不像勃艮第那麼昂貴，但非常優雅，很適合今晚的場合。」

1. 觀察點菜內容，主動出擊提供建議。

2. 推薦\*\*中庸之道\*\*的酒款（如輕盈黑皮諾、灰皮諾或粉紅酒），並解釋其「百搭」的特性。

3. 建議點選\*\*單杯\*\*或\*\*瓶\*\*，避免給顧客點整瓶的壓力。

4. 開始進入服務流程從上酒杯、介紹酒款內容、開瓶、送軟木塞、醒酒、優雅地倒酒。

### \*\*情境二：商務宴請的體面\*\*

\* \*\*情境\*\*：一位中年主管宴請兩位重要客戶。主菜點了兩份肋眼牛排和一份烤羊排。

\* \*\*潛在需求\*\*：展現主人品味與誠意，預算較高，需要一款能鎮住場面、品質穩健的酒。

\* \*\*服務員\*\*：（對做東的主管）「先生您好，您們的主菜非常適合搭配一款風味濃郁的紅酒。今晚是否想來一瓶好紅酒助興？我們有幾款來自新世界知名酒廠的\*\*希哈（Shiraz）\*\*，飽滿強勁，非常適合搭配牛排。」

\* \*\*顧客\*\*：「有什麼具體推薦嗎？」

\* \*\*服務員\*\*：「我特別推薦這款\*\*澳洲巴羅莎谷（Barossa Valley）的希哈\*\*。它充滿了黑色水果和些許胡椒的香氣，口感豐厚，單寧成熟，與牛肉的油脂和香氣是絕配，能充分展現您們今晚選擇的菜餚風味。」

1. 認清誰是主人，主要與其對話，並用眼神照顧其他客人以示尊重。

2. 推薦\*\*知名度高、品質穩定\*\*的產區和品種（如納帕谷卡本內蘇維翁、波爾多左岸、澳洲希哈）。

3. \*\*展示酒標\*\*讓主人確認。

4. 標準侍酒流程：開瓶→請主人試飲→得到確認後，\*\*先為客人斟酒，最後才為主人斟酒\*\*。

### \*\*情境三：慶祝紀念日的溫馨\*\*

\* \*\*情境\*\*：一對夫妻慶祝結婚紀念日，點了烤雞和蘑菇燉飯。

\* \*\*潛在需求\*\*：追求浪漫溫馨的氛圍，酒款不需要強勁，但要優雅可口。

\* \*\*服務員\*\*：（微笑）「恭喜兩位！今晚為您們準備了一點小驚喜。看到您們點的菜餚，或許來一瓶帶有圓潤口感和堅果香氣的\*\*白葡萄酒\*\*會很合適？能讓蘑菇的風味更上一層樓。」

\* \*\*顧客\*\*：「有什麼推薦的嗎？」

\* \*\*服務員\*\*：「一款經典的\*\*法國勃艮地白葡萄酒（Bourgogne Blanc）\*\*，由夏多內（Chardonnay）釀造。它口感圓潤，帶有柑橘、熱帶水果和一絲奶油的香氣，非常順口優雅，和您們的菜餚與今晚的氣氛都會很搭配。」

1. 真誠地道賀，營造歡樂氛圍。

2. 推薦\*\*經典、順口、接受度高\*\*的酒款（如夏多內、黑皮諾、氣泡酒）。

3. 可主動提出「是否需要幫二位拍張照？」，增加互動。

4. 最後可贈送一份小甜點或兩杯餐後酒（如貴腐酒）以示祝賀。

### \*\*情境四：葡萄酒愛好者的挑戰\*\*

\* \*\*情境\*\*：一位顧客仔細閱讀酒單，並詢問幾個專業問題，顯然對葡萄酒很有研究。

\* \*\*潛在需求\*\*：希望找到獨特、不流於俗套的酒款，期待專業的交流。

\* \*\*服務員\*\*：「看來您對葡萄酒很有心得。我們最近剛進了一批來自\*\*奧地利溫德瑞（Wachau）的麗絲玲（Riesling）\*\*，是『Smaragd』等級的，風味非常集中，有漂亮的礦石感和酸度，不同於德國的風格，您有興趣試試看嗎？」

\* \*\*顧客\*\*：「聽起來很有趣，是乾型的嗎？」

\* \*\*服務員\*\*：「是的，是完全乾型的。它的陳年潛力很好，搭配海鮮或亞洲菜餚都非常出色。或者，我們也有一款自然派（Natural Wine）的橘酒（Orange Wine），風格非常獨特。」

1. 傾聽顧客的問題，判斷其知識水平。

2. 推薦\*\*小眾產區、特殊品種或釀造法\*\*的酒款，展現酒單深度。

3. 使用專業術語，進行\*\*平等交流\*\*而非單方面推銷。

4. 討論適飲溫度與杯型選擇，提供專業的侍酒服務。

### \*\*情境五：顧客猶豫不決時\*\*

\* \*\*情境\*\*：一桌四位顧客面對酒單討論許久，無法達成共識。

\* \*\*潛在需求\*\*：需要一個權威的建議來打破僵局，或者需要更靈活的選擇。

\* \*\*服務員\*\*：「各位好，需要幫忙嗎？看到大家點的主菜有魚有肉，或許可以考慮點選\*\*單杯酒（Wine by Glass）\*\*，這樣每位都可以選擇自己喜歡的風格。或者，來一瓶\*\*粉紅酒（Rosé）\*\*？它幾乎是百搭的，清爽又開胃。」「如果不喝酒，我們也有零酒精配餐方案。例如這款冷泡烏龍帶花香，很適合您點的白肉主菜。」

1. 主動介入，提供解決方案。

2. 提出\*\*折衷方案\*\*（如單杯酒、半瓶裝、香檳/氣泡酒開胃、無酒精飲料）。

3. 快速歸納顧客點的菜餚風格，給出2個最安全的選擇。

4. 迅速執行決定，避免讓顧客繼續糾結。

### \*\*情境六：搭配辛辣亞洲菜餚\*\*

\* \*\*情境\*\*：顧點點了泰式綠咖哩、宮保雞丁等辛辣菜餚。

\* \*\*潛在需求\*\*：需要能解辣、清爽且帶點甜味的酒。

\* \*\*服務員\*\*：「您們的菜餚風味豐富且有些辛辣。我建議選擇一款\*\*微甜帶酸的白酒\*\*，它的甜味可以中和辣味，酸度可以清新口腔。一款\*\*德國半乾型麗絲玲（Kabinett或Spatlese）」\*\* 會是完美的選擇。」

\* \*\*顧客\*\*：「白酒？但我們也有紅肉菜餚。」

\* \*\*服務員\*\*：「對於辛辣菜餚，單寧重的紅酒會加重苦味。這款麗絲玲的風味強度足以駕馭紅肉，請不用擔心。或者，一款果味充沛、幾乎沒有單寧的\*\*佳美（Gamay）\*\* 紅酒（如博若萊）也是好選擇。」

1. 打破「紅肉配紅酒」的刻板印象，提供專業建議。

2. 解釋\*\*風味搭配的科學原理\*\*（甜抵辣、酸解膩）。

3. 大膽推薦\*\*特定風格的甜白或輕盈紅酒\*\*。

4. 可先提供一小杯讓顧客試嘗，以說服他們。

### \*\*情境七：顧客對推薦酒款表示不滿意\*\*

\* \*\*情境\*\*：服務員按流程請主人試飲推薦的酒後，主人皺眉表示：「這味道好像有點太澀了/太酸了。」

\* \*\*潛在需求\*\*：酒款不符合預期，需要更換，但不想顯得尷尬或挑剔。

\* \*\*服務員\*\*：（立即回應）「當然沒問題，感謝您誠實告知。或許這款酒的風格與您的預期有些不同。讓我們為您換另一款試試好嗎？您比較偏好\*\*口感更柔順、果味更豐富\*\*一點的風格嗎？」

1. \*\*絕對不要爭辯\*\*，立即道歉並接受顧客的意見。

2. 透過提問，\*\*重新確認顧客的偏好\*\*（是太澀？太酸？還是木桶味太重？）。

3. 根據新的信息，\*\*推薦另一款截然不同的酒\*\*（如從卡本內換成梅洛，從夏多內換成白蘇維濃）。

4. 將換下的酒瓶帶回，並向經理說明情況，通常這瓶酒會成為員工訓練品。

### \*\*情境八：餐後甜酒與烈酒的推廣\*\*

\* \*\*情境\*\*：顧客用餐完畢，正在看甜點 menu。

\* \*\*潛在需求\*\*：為完美的晚餐畫下句點，或想坐著繼續聊天。

\* \*\*服務員\*\*：「各位今晚用餐還愉快嗎？我們主廚特製的巧克力熔岩蛋糕，搭配一杯\*\*陳年波特酒（Tawny Port）\*\* 簡直是天作之合。波特酒的堅果和焦糖風味能完美提升巧克力的風味。或者，來一杯\*\*單一麥芽威士忌\*\*或\*\*干邑白蘭地\*\*純飲，幫助消化也不錯。」

1. 在適當時機（上甜點前）主動推薦。

2. 提出\*\*具體的搭配建議\*\*（如貴腐酒配藍紋乳酪、波特酒配巧克力、雪莉酒配堅果）。

3. 展示酒瓶，並介紹其背景故事。

4. 使用正確的杯具（如烈酒杯、甜酒杯）提供服務。

### \*\*情境九：顧客自帶酒水（BYOB）\*\*

\* \*\*情境\*\*：顧客帶來一瓶自己珍藏的酒，詢問開瓶服務。

\* \*\*潛在需求\*\*：希望分享珍愛的美酒，並得到專業的侍酒服務。

\* \*\*服務員\*\*：（熱情地）「當然可以，這是一款很好的酒！我們會為您提供合適的杯具並以適飲溫度服務。按照餐廳規定，我們會收取一點開瓶服務費，您看可以嗎？」

1. 先確認餐廳是否接受BYOB及相關收費規定。

2. \*\*讚美顧客的酒\*\*，建立好感。

3. 提供\*\*專業的侍酒服務\*\*（檢查狀態、換瓶醒酒、控制溫度），彷彿這瓶酒來自餐廳酒窖。

4. 適時詢問酒款品飲心得，展現興趣與專業。

### \*\*情境十：推薦給什麼都不想點的顧客\*\*

\* \*\*情境\*\*：顧客表示「我們不喝酒」或「今天不想喝」。

\* \*\*潛在需求\*\*：可能只是不想喝酒精，或是需要一個更有吸引力的理由。

\* \*\*服務員\*\*：「完全理解。那或許可以試試我們的\*\*無酒精調飲（Mocktail）\*\*？我們有一款用新鮮芭樂、檸檬和薄荷特調的飲品，非常清爽開胃。或者，來一瓶\*\*氣泡礦泉水\*\*佐餐，也能提升食物的風味喔！」
