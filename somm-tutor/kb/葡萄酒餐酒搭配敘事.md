# 葡萄酒餐酒搭配敘事

包含 **「酒款特性 → 料理特性 → 搭配原理 → 引導客人品飲 → 感官結果」**

**Chenin Blanc 的特色是高酸度、果香與花香明顯，而且從乾型、半乾型、甜型到氣泡酒都有，因此餐酒搭配的彈性非常高。**

**以下以「侍酒師對客人說的專業敘事」來設計 10 組，可直接用於餐廳侍酒服務、短影音旁白或教學情境。**

| **搭配** | **專業侍酒師敘事** |
| **1. 生蠔 × Dry Chenin Blanc** | 「這款乾型 Chenin Blanc 有明亮的酸度與清新的柑橘、青蘋果氣息，很適合搭配生蠔。酒中的酸度能提升生蠔的鮮甜與海洋礦物感，入口乾淨俐落，讓下一口依然保持清爽。」 |
| **2. 香煎干貝 × Chenin Blanc** | 「香煎干貝帶有天然甜味與焦香，我會搭配帶有梨子、蘋果與蜂蜜氣息的 Chenin Blanc。清爽酸度平衡干貝的甜潤，而酒中的果香則與焦糖化表面形成漂亮呼應，讓味道更加細緻。」 |
| **3. 清蒸鱸魚 × Dry Chenin Blanc** | 「清蒸鱸魚講究魚肉本身的細嫩與鮮味，因此不需要太濃重的酒款。乾型 Chenin Blanc 的柑橘、白花與清脆酸度，可以襯托魚肉鮮甜，而不掩蓋料理本身的細膩風味。」 |
| **4. 烤雞 × Oaked Chenin Blanc** | 「烤雞表面的焦香與肉汁，需要稍有厚度的白酒。經橡木桶熟成的 Chenin Blanc 帶有成熟蘋果、蜂蜜、香草與烘烤氣息，可以呼應雞肉的焦香，同時用酸度平衡油脂。」 |
| **5. 泰式檸檬蝦 × Off-Dry Chenin Blanc** | 「泰式料理同時有酸、辣、甜與香料，因此我會選擇微甜型 Chenin Blanc。少量殘糖能柔化辣感，明亮酸度呼應檸檬，而熱帶水果與花香則能與香料形成更豐富的層次。」 |
| **6. 四川辣味料理 × Off-Dry Chenin Blanc** | 「面對麻辣料理，我不會選擇單寧強烈的紅酒，而會推薦微甜型 Chenin Blanc。它的果香與微甜感可以緩和辣椒帶來的刺激，高酸度則能刷新味蕾，讓麻、辣、香與果味保持平衡。」 |
| **7. 奶油海鮮義大利麵 × Chenin Blanc** | 「奶油醬汁需要一款既有酸度又有酒體的白酒。Chenin Blanc 的酸度可以切開奶油的厚重感，而成熟梨子、蘋果與淡淡蜂蜜風味，又能與海鮮的甜味自然融合，使整體口感濃郁卻不膩。」 |
| **8. 山羊乳酪 × Loire Chenin Blanc** | 「山羊乳酪的酸香與乳脂感，非常適合 Chenin Blanc。酒中的高酸度與乳酪形成清爽呼應，而蘋果、柑橘、花香與礦物感則增加風味層次，是非常典型的法式搭配思維。」 |
| **9. 台式鹽酥雞 × Sparkling Chenin Blanc** | 「如果想把台灣街頭美食變成餐酒體驗，我會用氣泡型 Chenin Blanc 搭配鹽酥雞。細緻氣泡與高酸度能清潔炸物留下的油脂感，而清新的果香則讓胡椒、九層塔與炸雞香氣變得更加活潑。」 |
| **10. 蘋果塔 × Sweet Chenin Blanc** | 「甜點搭酒有一個重要原則：酒的甜度最好不要低於甜點。甜型 Chenin Blanc 帶有蜂蜜、熟蘋果、杏桃與果乾氣息，與蘋果塔的焦糖及烘烤香形成呼應，同時保留足夠酸度，使收尾甜而不膩。」 |

例如端上 **香煎干貝 × Chenin Blanc** 時，不必只說「這款酒適合海鮮」，可以這樣描述：

請您先感受這款 Chenin Blanc 的香氣。杯中可以找到清新的青蘋果、成熟梨子，以及淡淡白花與蜂蜜氣息。

今天我特別用它搭配香煎干貝。當干貝表面煎出漂亮的金黃色澤，焦香會把它原本的鮮甜帶出來；這時喝一口 Chenin Blanc，明亮的酸度會讓味蕾重新變得清爽，而酒中的梨子與蘋果果香，則會和干貝的甜味自然交會。

您可以先品嚐一口干貝，再喝一小口酒。您會發現，酒不是把料理的味道蓋掉，而是讓干貝的鮮甜、焦香與葡萄酒的果香，一層一層展開。

這就是我選擇這款 Chenin Blanc 的原因——它不是料理旁邊的一杯酒，而是讓這道料理變得更完整的最後一個元素。

\*\*Sauvignon Blanc（白蘇維濃）\*\*非常適合做專業餐酒搭配敘事，核心可抓住它常見的 **高酸度、柑橘、葡萄柚、百香果、青草、香草植物與礦物感**；不同產區又能呈現從清脆草本到成熟熱帶水果的風格差異。

以下 10 組特別用「**侍酒師向賓客介紹餐酒搭配**」的口吻撰寫，可直接用於餐廳桌邊服務、教學或短影音旁白。

| **10. 香草烤雞 × Fumé Blanc** | 「如果是帶迷迭香、百里香的烤雞，我會選擇風格稍微成熟的 Fumé Blanc。Sauvignon Blanc 原有的酸度與草本氣息能呼應香草，而適度橡木桶帶來的煙燻、香草與烘烤調性，又能接住雞皮的焦香，使酒與料理更有深度。」 |

以 **Sauvignon Blanc × 泰式檸檬魚** 為例，與其只告訴客人「白酒很適合魚」，可以把品飲體驗說出來：

今天為您搭配的是一款 Sauvignon Blanc。您可以先聞一下杯中的香氣，會感受到葡萄柚、萊姆與百香果的清新果香，後段還帶著淡淡的青草與香草植物氣息。

我特別選擇它搭配今天的泰式檸檬魚。當您先品嚐魚肉，會感受到檸檬的酸香、辣椒的刺激，以及魚肉本身細緻的鮮甜；接著喝一小口 Sauvignon Blanc，明亮的酸度會讓口腔重新變得清爽，而酒中的柑橘與熱帶水果香氣，會與料理中的檸檬形成自然呼應。

最後，酒裡細緻的草本氣息又會和香菜等香料連結起來。您會發現，魚肉的鮮甜沒有被酒蓋過，反而變得更明亮、更有層次。

這就是 Sauvignon Blanc 很迷人的地方——它不只是搭配海鮮，而是利用酸度、果香與草本氣息，把料理裡原本存在的風味重新放大。

Riesling 的餐酒搭配能力非常強，核心在於**高酸度、柑橘與核果香氣、花香，以及從極乾型到甜型的廣泛甜度**。因此不只適合海鮮，對亞洲料理的酸、甜、辣、鹹也很有優勢。

| **餐食搭配** | **專業侍酒師搭配敘事** |

| **4. 泰式酸辣蝦 × Off-Dry Riesling** | 「面對酸、辣、甜同時存在的泰式料理，我會選擇微甜型 Riesling。適度殘糖可以柔化辣椒的刺激感，高酸度則呼應萊姆的酸香；桃子、柑橘與花香又能接住香茅與香料，讓味道活潑卻不失平衡。」 |
| **5. 四川麻辣料理 × Off-Dry Riesling** | 「麻辣料理並不一定需要濃郁紅酒。微甜型 Riesling 反而很有優勢：甜度能柔化辣感，高酸度重新整理味蕾，而桃子、杏桃與花香則與辛香料形成有趣對比。每喝一口，都像替味蕾重新開機，再迎接下一口麻辣。」 |
| **6. 北京烤鴨 × Riesling Kabinett** | 「北京烤鴨同時有酥脆油脂、肉香、甜麵醬與蔥香。我會選擇帶些微甜感的 Riesling Kabinett。酸度能切開鴨皮油脂，細緻甜度呼應甜麵醬，而柑橘、桃子與花香則讓鴨肉的風味變得更加輕盈。」 |
| **7. 台式鹽酥雞 × Sparkling Riesling** | 「鹽酥雞的酥脆、油脂、胡椒與九層塔，需要一款能刷新味蕾的酒。氣泡型 Riesling 的酸度與氣泡可以清潔口腔中的油脂感，而柑橘與果香能襯托九層塔和香料，讓熟悉的台灣小吃呈現完全不同的餐酒體驗。」 |

| **9. 藍紋乳酪 × Sweet Riesling** | 「藍紋乳酪有強烈鹹味、乳脂與特殊熟成香氣，因此我會選擇甜型 Riesling。酒中的甜味可以平衡乳酪的鹹與辛香，高酸度則切開濃厚乳脂，而蜂蜜、杏桃與熟成果香能讓原本強烈的味道變得圓潤。」 |
| **10. 水果塔 × Late Harvest Riesling** | 「水果塔的酸甜與奶油感，非常適合晚摘型 Riesling。酒中的蜂蜜、熟桃、杏桃與柑橘香氣，可以呼應水果本身的風味；甜度承接甜點，高酸度則避免整體變得甜膩，最後留下明亮而悠長的收尾。」 |

今天為您搭配的是一款 Riesling Kabinett。您可以先感受杯中的香氣，會發現清新的青蘋果、白桃與柑橘，伴隨細緻花香，入口帶有明亮酸度與優雅的微甜感。

今天選擇它搭配北京烤鴨，是因為這道料理同時具有酥脆鴨皮、豐富油脂、肉香，以及甜麵醬的甜鹹滋味。

請先品嚐一口烤鴨，再喝一小口 Riesling。酒中的高酸度會讓鴨皮的油脂感迅速變得清爽；細緻的甜度則與甜麵醬自然呼應，而白桃與柑橘果香會讓鴨肉的香氣更加明亮。

當最後一點蔥香與酒中的花果香交會時，原本濃郁的烤鴨會呈現更輕盈、更有層次的風味。

這就是 Riesling 的魅力——它不是與料理競爭，而是用酸度、甜度與香氣，讓每一種味道找到更好的平衡。

**Chardonnay（夏多內／霞多麗）最大的餐酒搭配優勢，是風格跨度非常大：未經橡木桶熟成的 Chardonnay 常呈現檸檬、青蘋果、白花、礦物感與清爽酸度**；經橡木桶與酒泥熟成的風格，則可能展現**熟蘋果、鳳梨、奶油、香草、烘烤與堅果氣息**。

因此，專業搭配不能只說「Chardonnay 配海鮮」，而要先判斷**酒體、酸度、橡木桶程度與料理的油脂、醬汁及烹調方式**。

| **2. 清蒸鱸魚 × Unoaked Chardonnay** | 「清蒸鱸魚最重要的是魚肉細嫩與自然鮮甜，因此我會選擇未經橡木桶熟成的 Chardonnay。清新的柑橘、蘋果與明亮酸度不會掩蓋魚肉，反而能提升鮮味，讓料理呈現更乾淨、更細緻的層次。」 |
| **3. 香煎干貝 × Chardonnay** | 「干貝經過香煎後會產生迷人的焦糖化香氣，而 Chardonnay 的熟蘋果、柑橘與柔和奶油感，可以延伸干貝本身的甜味。酒中的酸度則把奶油與焦香重新拉回平衡，讓下一口依然保持清爽。」 |
| **4. 奶油龍蝦 × Oaked Chardonnay** | 「奶油龍蝦需要一款有足夠酒體支撐的白酒。經橡木桶熟成的 Chardonnay 帶有奶油、香草、熟蘋果與烘烤氣息，可以與龍蝦的甜味和奶油醬汁形成風味呼應；酸度則負責平衡濃郁感，讓料理豐厚卻不膩口。」 |
| **5. 奶油白醬義大利麵 × Oaked Chardonnay** | 「白醬義大利麵的核心是奶油、乳脂與柔滑質地，因此我會選擇酒體較飽滿的 Chardonnay。酒中的奶油、香草與烘烤風味能與醬汁自然融合，而酸度像一道乾淨的線條，切開乳脂，使整體更加平衡。」 |
| **6. 香草烤雞 × Chardonnay** | 「烤雞的雞皮焦香、肉汁與迷迭香，需要一款既有酒體又有酸度的 Chardonnay。成熟果香可以襯托雞肉的甜味，橡木桶帶來的香草與烘烤氣息則呼應雞皮焦香，使料理與葡萄酒在口中自然連接。」 |
| **7. 烤鮭魚 × Medium/Full-Bodied Chardonnay** | 「鮭魚的油脂比一般白肉魚豐富，因此需要更有結構的白酒。中至飽滿酒體的 Chardonnay 可以承接鮭魚的質感，而酸度則清理油脂；如果料理帶有奶油或烘烤香，橡木桶 Chardonnay 的香草與烘烤調性會更加契合。」 |
| **8. 烤豬肉 × Oaked Chardonnay** | 「白酒也能搭配豬肉。烤豬肉具有肉汁、油脂與焦香，我會選擇酒體較豐滿的橡木桶 Chardonnay。熟蘋果、香草與烘烤氣息能呼應肉香，而酸度則降低油膩感，讓豬肉的甜味更加突出。」 |
| **9. 烤蘑菇 × Barrel-Aged Chardonnay** | 「蘑菇帶有明顯的泥土、鮮味與烘烤氣息，搭配桶陳 Chardonnay 會非常有趣。酒中的烘烤、堅果、香草調性可以與蘑菇形成香氣橋接，而果香與酸度則讓整體不會過度厚重，呈現溫暖而有深度的搭配。」 |
| **10. 台式鹽酥雞 × Sparkling Chardonnay** | 「如果想把 Chardonnay 帶進台灣年輕人的餐桌，我會用以 Chardonnay 為主的氣泡酒搭配鹽酥雞。清脆酸度與細緻氣泡可以刷新炸物的油脂感，柑橘、蘋果香氣襯托雞肉，而酵母、烘烤氣息則能與炸衣的香脆感形成呼應。」 |

這一組很能展現 Chardonnay 的「**酒體 × 酸度 × 橡木桶 × 奶油質地**」搭配邏輯。

今天為您搭配的是一款經過橡木桶熟成的 Chardonnay。您可以先感受杯中的香氣，會發現成熟蘋果、柑橘與些許熱帶水果氣息，接著慢慢出現香草、奶油與細緻的烘烤香。

今天選擇它搭配奶油龍蝦，是因為龍蝦本身具有細緻的鮮甜與彈性，而奶油醬汁又增加了料理的濃郁度與柔滑口感。

請先品嚐一口龍蝦，再喝一小口 Chardonnay。您會發現，葡萄酒圓潤的酒體可以承接龍蝦與奶油醬汁的豐厚質地，而酒中的香草與烘烤氣息，會和料理的奶油香形成自然呼應。

接著，Chardonnay 明亮的酸度會慢慢把口中的乳脂感帶走，讓龍蝦原本細緻的鮮甜重新浮現。

這就是這組搭配迷人的地方——料理讓 Chardonnay 顯得更加圓潤豐富，而 Chardonnay 又讓龍蝦的鮮甜更加清晰。兩者不是互相掩蓋，而是在口中完成彼此。

**🍏 專業搭配時，可以掌握一個核心**

**清爽型 Chardonnay → 清蒸魚、生蠔、清淡海鮮**
**中等酒體 Chardonnay → 干貝、鮭魚、烤雞**
**桶陳濃郁 Chardonnay → 龍蝦、奶油醬汁、烤豬肉、蘑菇**

也就是：**酒越濃郁，料理的質地與醬汁也可以越濃郁；橡木桶越明顯，就越適合尋找奶油、焦香、烘烤、堅果等風味來呼應。**
