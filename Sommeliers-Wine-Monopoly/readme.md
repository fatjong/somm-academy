## 一、如何使用

整個遊戲是**單一 HTML 檔（約 4.2 MB，已內嵌兩首 BGM 與校徽）**，不需要任何外部檔案。

| 使用方式 | 做法 |
|---|---|
| 老師電腦 / 教室 | 雙擊 `餐酒服務大富翁.html` 直接開啟 |
| 給學生上網玩 | 上傳到學校網頁空間、Google Sites、GitHub Pages、Netlify 等任何靜態空間 |
| 手機 / 平板 | 用瀏覽器開啟同一個網址即可，介面已做手機適配 |

> **音樂自動播放**：瀏覽器規定必須有使用者互動才能播放聲音，因此進入首頁後**點一下畫面（或按任一按鈕）音樂就會開始**。首頁可即時調整兩首 BGM 的音量，遊戲畫面右上角的 🎵 按鈕可隨時靜音。

## 二、遊戲流程

1. **登入**：輸入「學號＋姓名」（例：`A1234567890王小明`），限 20 字元，需同時含英數學號與中文姓名。
2. **選擇模式**
   - 🤖 **單人挑戰**：與 NPC 對奕
   - 🏰 **遊戲空間**：15 個空間、**每間最多 3 人**
   - 所有空間滿員時進入 **線上等待**（可查看排隊順位），也可改為單人挑戰
3. **遊戲空間配對（線上模式）**：第 1 位玩家進入後開始 **3 分鐘倒數** ——
   - 湊滿 **3 人** → 不等倒數，立即開始
   - 倒數結束有 **2 人** → 直接 2 人 PK
   - 倒數結束仍只有 **1 人** → 自動退回大廳
   - **遊戲空間內不配置 NPC**（要跟 NPC 練習請選「🤖 單人挑戰」）
4. **起點**：系統隨機抽一格作為起點（**不作答**），所有玩家離開後起點格自動消失。
5. **闖關**：擲骰子（1–6 點，含 3D 動畫）前進 → 翻開任務卡（切換為答題 BGM）→ 完成該格 2～3 題 → 關卡結束切回主 BGM。敘事題可按 **🎤 語音輸入** 用說的作答。
6. **結算**：生命值歸零者淘汰；最後存活者成為侍酒大富翁。

### 數值規則

| 項目 | 初始 | 規則 |
|---|---|---|
| ❤️ 服務心（生命值） | 10 | 該格全部答錯（被客訴）−1 |
| 🪙 Wine Coin | 5 | 該格全對 +1；使用提示卡 −5 |
| ⭐ Sommelier Point | 0 | 每答對一題 +1 ← **最終勝出標準** |
| ⏱ 作答時間 | 30 秒／題 | 逾時 → 判定答錯 ＋ **強制進入下一題**；最後一題則強制完成關卡（第 24、25 格敘事題為 60 秒） |
| ⏱ 擲骰時間 | 30 秒 | 逾時 → 系統**自動代擲**，避免其他玩家乾等 |

### 勝負判定

- ❤️ 歸零者淘汰，可續留觀戰或退出，**最後存活者勝出**
- 若進行至第 **125 回合** 仍無人勝出 → **⭐ Sommelier Point 最高者**判為侍酒大富翁
  （同分時依序比較 🪙 Wine Coin → ❤️ 剩餘服務心）

## 三、25 格關卡設計（由知識到能力的學習階梯）

| 區域 | 格數 | 核心能力 |
|---|---|---|
| 🍇 第一區｜酒款偵探村 | 1–5 | 酒款與風味辨識 |
| 🍽️ 第二區｜料理分析村 | 6–10 | 食物風味分析 |
| 🍷 第三區｜餐酒搭配王國 | 11–16 | 正確選酒（第 16 格為 BOSS） |
| 🗣️ 第四區｜侍酒師敘事大道 | 17–21 | 專業推薦與顧客關係 |
| 👑 第五區｜五星侍酒師實戰區 | 22–25 | 綜合應用（第 25 格為 FINAL BOSS） |

**題庫共 110 題**：每格「核心題」為原始設計題目；**重複經過同一格時會改出「延伸題」**，內容取自三份教材（Chenin Blanc、Chardonnay、Pinot Gris、Gamay、Garnacha、Merlot、Nebbiolo 的搭配公式，以及智利 Maipo、奧地利綠維特利納、德國 Riesling 分級等產區知識）。

題型包含：單選、複選、配對、排序、**專業敘事（關鍵字檢核）**。敘事題會即時顯示 🔑 關鍵概念是否命中，作答後提供**專業侍酒師範例話術**。

## 四之二、🎤 語音輸入（STT）

所有需要打較多字的**敘事題**都會出現「🎤 語音輸入」按鈕。

- 按一下開始錄音 → 直接把侍酒推薦「說」出來 → 文字會即時出現在作答框
- 錄音中會顯示灰色斜體的即時辨識文字，確定後轉為正式文字
- 下方 🔑 關鍵概念會**邊說邊亮**，學生馬上知道還缺哪個要素
- 再按一次「⏹ 停止錄音」結束，可反覆補充
- 錄音時背景音樂自動降到 35%，減少干擾

| 瀏覽器 | 支援 |
|---|---|
| Chrome（電腦 / Android） | ✅ 建議使用 |
| Microsoft Edge | ✅ |
| Safari（Mac / iPhone） | ⚠️ 部分版本支援 |
| Firefox | ❌ 自動改為鍵盤作答（按鈕顯示「不支援」） |

> 第一次使用時瀏覽器會詢問麥克風權限，請按「允許」。
> 網頁若放在 **https://** 網址下才能使用麥克風；用 `file://` 直接開啟本機檔案在 Chrome 也可以，但用區網 `http://` 網址則不行。

## 五、教師後台

登入畫面或大廳右上角 → **🔐 教師後台**，預設密碼 **620620**。

密碼以 `SHA-256 + 加鹽` 雜湊儲存，**原始碼中不含明碼**。可在後台自行更換密碼。

後台功能：

- **📊 成績總覽**：所有玩家等級、總分、四個能力向度百分比、遊玩次數
- **👑 名人堂**：所有侍酒大富翁勝出紀錄（永久保留）
- **📚 題庫檢視**：25 格 110 題完整題目與標準答案，可直接印給學生當講義
- **⚙️ 設定**：作答秒數、提示卡花費、初始生命值 / Wine Coin、**兩首 BGM 音量**、Firebase 設定
- **⬇ 匯出 CSV**：一鍵匯出成績（含 UTF-8 BOM，Excel 直接開啟不亂碼）

## 六、Firebase 線上多人對接（專案：sommeliers-wine-monopoly）

> 📘 **想要更詳細、一步一步的圖文版？請開啟隨附的《Firebase對接教學.html》**，
> 裡面有中英文介面對照、每一步「成功的樣子」、測試連線三種結果的處理方式，以及疑難排解表。
> 下面是精簡版流程。

預設為**離線模式**：成績存在瀏覽器本機，遊戲空間可進行「同機輪流 2–3 位真人玩家」對戰（不含 NPC），單人則用「🤖 單人挑戰」與 NPC 對奕。
要開啟**跨裝置線上對戰與雲端成績**，請照以下步驟：

### 步驟 1｜建立 Realtime Database

1. 開啟 [Firebase 控制台 → sommeliers-wine-monopoly](https://console.firebase.google.com/project/sommeliers-wine-monopoly/overview)
2. 左側 **建構 Build → Realtime Database → 建立資料庫**
3. 位置建議選 **`asia-southeast1`（新加坡）**，台灣連線延遲最低
4. 安全性規則先選「**以測試模式啟動**」（上課前再改成下方的正式規則）
5. 建立完成後，**把畫面上方顯示的資料庫網址複製起來**，格式會是：
   - 亞洲區：`https://sommeliers-wine-monopoly-default-rtdb.asia-southeast1.firebasedatabase.app`
   - 美國區：`https://sommeliers-wine-monopoly-default-rtdb.firebaseio.com`

### 步驟 2｜啟用匿名登入

左側 **建構 Build → Authentication → 開始使用 → Sign-in method → 匿名 → 啟用**
（遊戲用匿名帳號辨識每位玩家的連線，學生不需要註冊。）

### 步驟 3｜取得網頁應用程式金鑰

1. 左上齒輪 **⚙️ 專案設定 → 一般**
2. 下方「你的應用程式」→ 點 **網頁 `</>`** 圖示 → 註冊應用程式（名稱隨意，例如 `wine-monopoly-web`）
3. 畫面會顯示 `firebaseConfig`，複製其中的 **`apiKey`** 與 **`appId`**

### 步驟 4｜填入遊戲

1. 遊戲 → 🔐 教師後台（620620）→ **⚙️ 設定**
2. 按 **「📋 插入本專案範本」**，會自動填入：

```json
{
  "apiKey": "貼上你的 apiKey",
  "authDomain": "sommeliers-wine-monopoly.firebaseapp.com",
  "databaseURL": "https://sommeliers-wine-monopoly-default-rtdb.asia-southeast1.firebasedatabase.app",
  "projectId": "sommeliers-wine-monopoly",
  "storageBucket": "sommeliers-wine-monopoly.firebasestorage.app",
  "appId": "貼上你的 appId"
}
```

3. 把步驟 3 的 `apiKey`、`appId` 貼進去，並**確認 `databaseURL` 與控制台顯示的完全一致**
4. 按 **「🔌 測試連線」**：
   - ✅ 連線成功 → 表示可讀寫，沒問題
   - ⚠️ 已連上但寫入被拒 → 資料庫規則太嚴，請先改測試模式
   - ❌ 連線失敗 → 檢查是否已建立 Realtime Database、已啟用匿名登入、`databaseURL` 是否打錯
5. 按 **「💾 儲存設定」→ 重新登入**，大廳右上角應顯示「🌐 線上連線中」

### 步驟 5｜正式上課前收緊安全規則

Realtime Database → 規則，改成：

```json
{
  "rules": {
    ".read": "auth != null",
    ".write": "auth != null"
  }
}
```

### 對接後的效果

| 資料 | 儲存路徑 |
|---|---|
| 遊戲空間狀態與玩家位置 | `rooms/{roomId}/players`、`rooms/{roomId}/state` |
| 答題畫面即時分享（供同房玩家觀摩） | `rooms/{roomId}/live` |
| 玩家最佳成績 | `best/{學號姓名}` |
| 👑 侍酒大富翁名人堂（僅勝出者・永久保留） | `hall`（僅新增，不覆蓋） |
| 滿員排隊名單 | `queue/{uid}` |

> **重要**：`databaseURL` 一定要用控制台上的實際網址。若把亞洲區資料庫填成 `firebaseio.com` 的美國區網址，會出現「連線失敗」。

## 九、教學延伸建議

25 格 × 每格 2～3 題的規模，非常適合延伸做成：

- 實體大富翁棋盤 ＋ 25 張關卡卡（後台「題庫檢視」可直接列印）
- 每張關卡卡加上 QR Code，掃碼進入該格的 AI 語音侍酒挑戰
- 第 17、18、23、24、25 格的敘事題，可作為**桌邊服務口試**評分表

學生最後真正形成的專業思考流程：

**料理分析 → 酒款分析 → 選酒 → 搭配理由 → 顧客需求 → 服務敘事**
