## 🆕 v2.0 重大更新

1. **玩家帳號系統**：註冊（玩家帳號＋密碼＋Email）→ 收驗證信 → 完成驗證才能線上對戰；支援忘記密碼。
2. **一組 Email 只能開通一個玩家**；變更 Email 後需重新驗證。
3. **防暴力破解**：玩家登入與教師後台密碼**連續錯 3 次即鎖定 3 分鐘**（欄位反灰、不顯示倒數）。
4. **同帳號最多 3 個同時在線**，第 4 個裝置會被拒絕登入（防多開掛機）。
5. **同一遊戲空間不可用同一帳號重複入座**。
6. **選擇題選項每次隨機打亂**，必須真的答對才會計分。
7. **NPC 動態難度**：依玩家目前正確率調整，永遠略低於玩家水準（下限 28%、上限 80%）。
8. **訪客觀戰**：進行中的空間可按「👁 進入觀戰」旁觀，完整看到走位動畫與對手正在作答的題目。
9. **玩家帳戶管理**：大廳「👤 帳戶管理」可改 Email／密碼、設定生日、上傳或選擇頭像，並顯示建立時間、等級與驗證狀態。
10. **修正**：遊戲空間倒數結束時，1 人會正確退回大廳、2 人會正確開賽。
11. **離線練習模式**：沒網路或不想註冊時，可用暱稱進行單人挑戰與同機對戰。

> ⚠️ **教師必做**：Firebase 控制台 → Authentication → Sign-in method → **啟用「電子郵件/密碼」**，
> 並更新 Realtime Database 規則為新版《Firebase安全性規則.json》。詳見第六節。

### v2.0.4 新增：🗑 清除名人堂紀錄

教師後台「👑 名人堂」分頁新增 **備份成 CSV**、**重新整理**、**清除名人堂紀錄** 三顆按鈕。
清除可分別選擇「本機／雲端／連同個人最佳成績」，並需輸入「清除」兩個字二次確認。
雲端刪除需要**管理者**權限（同一分頁可一鍵把教師帳號設為管理者）——
這是為了讓一般學生只能新增自己的勝出紀錄，不能刪掉別人的。詳見第五之二節。

> ⚠️ 需一併更新《Firebase安全性規則.json》（新增 `admins` 節點）。

### v2.0.3 對戰體驗修正

1. **最後一人自動成為大富翁**：開賽後其他玩家全部離線或退出遊戲空間時，
   最後留在場上的玩家<b>直接判定勝出</b>，成績寫入名人堂，不必空等。
2. **修正線上對戰卡住不動**：換手後，輪到的那台裝置沒有啟動擲骰倒數，導致整局停滯。
   現在換手會由「輪到的人」自己接手倒數：
   - **30 秒未擲骰** → 系統自動代擲
   - **30 秒未作答** → 判為答錯，5 秒後強制進入下一題；若為最後一題則強制完成關卡
3. **卡關看門狗**：輪到的玩家整台裝置沒有回應（關掉分頁、斷網）超過 60 秒時，
   由其他玩家中座位最前的裝置自動把回合推給下一位，並公告「⏰ ○○○ 逾時未回應，跳過該回合」。
4. **等待方直接看到真實畫面**：原本只顯示一個簡化的文字視窗，
   現在等待方與觀戰訪客會看到<b>對方真正的任務卡</b>（唯讀）——
   情境敘述、洗牌後的選項、對方選了哪一個、答對答錯與解析，全部即時同步；
   卡片下方標示「👀 觀摩中・唯讀」，不會誤按。

### v2.0.2 新增：🔍 連線診斷（解決「無法註冊」）

登入畫面與註冊視窗都新增 **「🔍 連線診斷」** 按鈕，會逐項檢查並**直接寫出解決方式**：

| 檢查項目 | 檢查什麼 |
|---|---|
| 本機連線開關 | 教師後台是否把這台電腦的線上連線關掉了 |
| 開啟方式 | 是否用 `file://` 直接開啟本機檔案（**Firebase 帳號服務不支援**） |
| 網路狀態 | 瀏覽器是否連上網路 |
| 連線設定 | 內建／自訂的 Firebase 設定是否完整 |
| 載入 Firebase 程式庫 | `www.gstatic.com` 是否被校園網路封鎖（會自動改用 `cdn.jsdelivr.net` 備援） |
| 初始化專案 | 專案設定是否可用 |
| Realtime Database | 控制台是否已建立資料庫 |
| 帳號服務 | Authentication 是否已啟用 |
| Email/密碼登入方式 | 是否已在 Sign-in method 啟用「電子郵件/密碼」、網域是否已授權 |
| 資料庫讀寫 | 安全性規則是否已發布 |

按 **📋 複製結果** 可把整份檢查報告複製起來，貼給老師或網管。
❌ 的項目若是教師可自行處理的（登入方式／資料庫／規則／授權網域），旁邊會出現 **「▶ 開啟控制台」** 直接跳到該設定頁。

**若出現「Firebase 尚未啟用『電子郵件／密碼』登入方式」**：這是控制台設定，教師做一次即可，之後全班都能註冊：

1. 開啟 <https://console.firebase.google.com/project/sommeliers-wine-monopoly/authentication/providers>
2. 點 **電子郵件／密碼**（Email/Password）
3. 把**第一個開關**（啟用 Email/Password）打開 →「**儲存**」
   （下面那個「電子郵件連結（免密碼登入）」不用開）
4. 回到遊戲重新按「建立帳號」即可

另外，註冊／登入／忘記密碼失敗時，訊息會直接寫出**卡在哪一關**，不再只顯示「目前無法連線」。

> **最常見原因**：直接用滑鼠雙擊 HTML 檔（網址列顯示 `file:///…`）。
> Firebase 的帳號系統規定網頁必須放在網址上（`http://` 或 `https://`）。
> 解法見下方「六之二、必須放到網址上才能註冊登入」。

## 一、如何使用

整個遊戲是**單一 HTML 檔（約 4.2 MB，已內嵌兩首 BGM 與校徽）**，不需要任何外部檔案。

| 使用方式 | 做法 |
|---|---|
| 老師電腦 / 教室 | 雙擊 `餐酒服務大富翁.html` 直接開啟 |
| 給學生上網玩 | 上傳到學校網頁空間、Google Sites、GitHub Pages、Netlify 等任何靜態空間 |
| 手機 / 平板 | 用瀏覽器開啟同一個網址即可，介面已做手機適配 |

> **音樂自動播放**：瀏覽器規定必須有使用者互動才能播放聲音，因此進入首頁後**點一下畫面（或按任一按鈕）音樂就會開始**。首頁可即時調整兩首 BGM 的音量，遊戲畫面右上角的 🎵 按鈕可隨時靜音。

## 二、遊戲流程

1. **註冊 / 登入**
   - 首次使用：首頁按「✍️ 註冊新玩家」→ 填入<b>玩家帳號（學號＋姓名）</b>、Email、密碼 → 收驗證信 → 點擊連結完成驗證
   - 之後：以 **Email ＋ 密碼**登入
   - 忘記密碼：首頁「🔑 忘記密碼」→ 輸入 Email → 收重設信
   - 沒網路時：「📴 離線練習模式」只需暱稱即可練習（不計入雲端排行）
2. **選擇模式**
   - 🤖 **單人挑戰**：與 NPC 對奕
   - 🏰 **遊戲空間**：15 個空間、**每間最多 3 人**
   - 所有空間滿員時進入 **線上等待**（可查看排隊順位），也可改為單人挑戰
   - **👁 觀戰**：進行中的空間可按房間卡上的「👁 進入觀戰」旁觀學習
3. **遊戲空間配對（線上模式）**：第 1 位玩家進入後開始 **3 分鐘倒數** ——
   - 湊滿 **3 人** → 不等倒數，立即開始
   - 倒數結束有 **2 人** → 由 **2 位玩家直接 PK**（遊戲空間內不會加入 NPC）
   - 倒數結束仍只有 **1 人** → 自動退回大廳
   - 空間內玩家**全部離開**後，該空間自動重置，下一位進入者的倒數重新從 3:00 起算
4. **起點**：系統隨機抽一格作為起點（**不作答**），所有玩家離開後起點格自動消失。
5. **闖關**：擲骰子（1–6 點，含 3D 動畫）前進 → 翻開任務卡（切換為答題 BGM）→ 完成該格 2～3 題 → 關卡結束切回主 BGM。敘事題可按 **🎤 語音輸入** 用說的作答。
6. **結算**：生命值歸零者淘汰；最後存活者成為侍酒大富翁。

### 數值規則

| 項目 | 初始 | 規則 |
|---|---|---|
| ❤️ 服務心（生命值） | 10 | 該格全部答錯（被客訴）−1 |
| 🪙 Wine Coin | 5 | 該格全對 +1；使用提示卡 −5 |
| ⭐ Sommelier Point | 0 | 每答對一題 +1 ← **最終勝出標準** |
| ⏱ 作答時間 | 30 秒／題 | 逾時 → 判定答錯 ＋ **強制進入下一題**；最後一題則強制完成關卡（第 24、25 格敘事題為 60 秒） |
| ⏱ 擲骰時間 | 30 秒 | 逾時 → 系統**自動代擲**，避免其他玩家乾等 |

### 勝負判定

- ❤️ 歸零者淘汰，可續留觀戰或退出，**最後存活者勝出**
- 若進行至第 **125 回合** 仍無人勝出 → **⭐ Sommelier Point 最高者**判為侍酒大富翁
  （同分時依序比較 🪙 Wine Coin → ❤️ 剩餘服務心）

## 三、25 格關卡設計（由知識到能力的學習階梯）

| 區域 | 格數 | 核心能力 |
|---|---|---|
| 🍇 第一區｜酒款偵探村 | 1–5 | 酒款與風味辨識 |
| 🍽️ 第二區｜料理分析村 | 6–10 | 食物風味分析 |
| 🍷 第三區｜餐酒搭配王國 | 11–16 | 正確選酒（第 16 格為 BOSS） |
| 🗣️ 第四區｜侍酒師敘事大道 | 17–21 | 專業推薦與顧客關係 |
| 👑 第五區｜五星侍酒師實戰區 | 22–25 | 綜合應用（第 25 格為 FINAL BOSS） |

**題庫共 110 題**：每格「核心題」為原始設計題目；**重複經過同一格時會改出「延伸題」**，內容取自三份教材（Chenin Blanc、Chardonnay、Pinot Gris、Gamay、Garnacha、Merlot、Nebbiolo 的搭配公式，以及智利 Maipo、奧地利綠維特利納、德國 Riesling 分級等產區知識）。

題型包含：單選、複選、配對、排序、**專業敘事（關鍵字檢核）**。敘事題會即時顯示 🔑 關鍵概念是否命中，作答後提供**專業侍酒師範例話術**。

### 五之二、🗑 清除名人堂紀錄（每學期換班用）

教師後台 →「👑 名人堂」分頁，上方有三顆按鈕：

#### 👑 設定管理者（雲端清除權限，只需做一次）

雲端名人堂是全班共用的，安全性規則規定**一般玩家只能新增自己的勝出紀錄，不能刪除或竄改別人的**——
這樣才不會有學生把別人的紀錄洗掉。因此**刪除權限只開放給管理者**。

設定方式（部署完成後、學生登入之前做）：

1. 用**教師自己的帳號**登入遊戲 → 教師後台 → 「👑 名人堂」分頁

> 這個按鈕採**先到先得**設計（只有在還沒有任何管理者時能按），請務必在公告網址給學生之前先按。
> 若已經有人搶先設定，或想再增加一位管理者，請到 Firebase 控制台 → Realtime Database →
> 手動新增節點 `admins/<該教師的管理者 ID>`（ID 可在同一區塊按「📋 複製」取得）。

> ⚠️ 此功能需要 **v2.0.4 版的《Firebase安全性規則.json》**（新增了 `admins` 節點與刪除權限），

## 六、線上多人連線

### 預設行為

**開箱即用**：連線設定已內嵌在檔案中（經混淆處理，原始碼中查不到 apiKey／appId），
**開啟遊戲就會自動連線**，教師與學生都不需要做任何設定。

### 右上角連線燈號

大廳與遊戲畫面的右上角各有一顆小圓燈：

| 燈號 | 意義 |
|---|---|
| 🟢 綠燈 | 已連線 Google 雲端，可跨裝置配對、成績同步 |
| 🟡 黃燈閃爍 | 連線中… |
| 🔴 紅燈 | 離線模式（單人挑戰與同機對戰仍完全正常，成績存本機） |

滑鼠移到燈號上或點一下，會顯示目前狀態的文字說明。
連線中途斷網會自動轉為紅燈，網路恢復後自動轉回綠燈。

### 想讓某台電腦不連線？

教師後台 → **⚙️ 設定** → 「🌐 線上多人連線」→ 按 **🔴 在這台電腦關閉線上連線**。
此設定只影響該台電腦（存在該台瀏覽器中），適合考試或無網路環境使用。

### Firebase 控制台需完成的設定（只需做一次）

1. **建構 Build → Realtime Database → 建立資料庫**，位置選 `asia-southeast1（新加坡）`
2. **建構 Build → Authentication → Sign-in method → 啟用「電子郵件/密碼」** ← **v2.0 必做**
   （若還想保留教師後台的「🔌 測試連線」功能，可一併啟用「匿名」）
3. 若要上傳到學校網站：**Authentication → 設定 → 授權網域**，加入你的網域（例：`www.lhu.edu.tw`）
4. **Realtime Database → 規則**，貼上隨附的《**Firebase安全性規則.json**》內容 → 發布

### 六之二、必須放到網址上才能註冊登入（重要）

**單人挑戰、同機 2–3 人對戰、離線練習模式**：雙擊檔案直接開啟就能玩，完全正常。

**註冊、登入、跨裝置連線對戰**：必須把 `餐酒服務大富翁.html` 放到一個**網址**上。
這是 Google Firebase 的規定 —— 帳號服務只接受 `http://` 或 `https://` 開頭的網頁，
用 `file:///C:/Users/…` 直接開啟會被拒絕，畫面就會出現「目前無法連線，無法註冊」。

最簡單的三種放法（擇一即可）：

| 方式 | 步驟 | 需不需要另外設定授權網域 |
|---|---|---|
| **Firebase Hosting**（最推薦） | 控制台 → 建構 → Hosting → 依畫面指示上傳，網址為 `sommeliers-wine-monopoly.web.app` | 不用，預設已授權 |
| **學校網頁空間** | 用 FTP 上傳到學校主機 | 要，把學校網域加入 Authentication → 設定 → 授權網域 |
| **GitHub Pages** | 建立 repo → 上傳檔案 → Settings → Pages 開啟 | 要，把 `你的帳號.github.io` 加入授權網域 |

上傳後把網址發給學生即可，學生端不需要安裝任何東西。

> 想在單機測試也能註冊，可在檔案所在資料夾開啟命令列執行 `python -m http.server 8000`，
> 再用瀏覽器開 `http://localhost:8000/餐酒服務大富翁.html`（`localhost` 預設已在授權網域內）。

### 📧 關於驗證信與密碼重設信

純網頁（單一 HTML 檔）**無法直接使用 Gmail 的 SMTP 寄信** —— SMTP 密碼寫進網頁就等於公開，而且瀏覽器本身不能連 SMTP。
因此驗證信與密碼重設信改由 **Firebase Authentication 內建的郵件服務**寄出，免費、免伺服器、立即可用。

可在 **Authentication → Templates（範本）** 調整：

- **寄件者名稱**：改成「餐酒服務大富翁」
- **回覆地址（Reply-to）**：設為 `fatjong@gmail.com`，學生回信就會寄到你的信箱
- **信件內容**：可改成中文

> 寄件者網域固定為 `noreply@sommeliers-wine-monopoly.firebaseapp.com`（Firebase 規定，需自有網域才能更換）。
> 請提醒學生：驗證信可能被歸類到**垃圾郵件匣**。

#### 🚫 驗證信被判定為垃圾信

Firebase 用的是共用寄件網域，加上預設信件是英文、內容只有一條連結，很容易被 Gmail 收進垃圾郵件匣。
完整解法與**可直接複製的中文信件範本**請見隨附的《**驗證信中文化與防垃圾信設定.md**》，四個層次：

1. **信件中文化**（5 分鐘，先做這個）：Templates 語言切繁中，三個範本貼上中文主旨與內文，設定寄件者名稱與 Reply-to
2. **學生端**：標記「不是垃圾郵件」＋建立「不要歸類為垃圾郵件」篩選器
3. **學校管理員**：Google Workspace／M365 把 `sommeliers-wine-monopoly.firebaseapp.com` 加入白名單，全班一次生效
4. **自有網域**：Templates → 自訂網域，加 TXT／CNAME 記錄（最徹底，需資訊處協助，最久 24 小時生效）

遊戲內也內建 **「📩 沒收到信？」**（大廳未驗證橫幅上、註冊完成後自動彈出）：
顯示寄件者地址、可一鍵複製、直接開啟 Gmail 搜尋（含垃圾郵件匣）、教學生怎麼標記，並可就地重寄與確認驗證。

### ⚠️ 關於「您的安全性規則不夠完善」警告

如果只填 `{"rules":{".read":"auth != null",".write":"auth != null"}}`，Firebase 會顯示這則警告，原因是：

> 本遊戲使用**匿名登入**，任何人打開網頁都會自動取得 auth 身分，
> 因此 `auth != null` 等於「誰都能讀寫整個資料庫」。

隨附的《Firebase安全性規則.json》用**分路徑授權**解決這個問題，貼上並發布後警告就會消失：

| 路徑 | 授權範圍 |
|---|---|
| `users/$uid` | 只有本人能寫自己的個人資料 |
| `accounts/$帳號` | 只能新增、不能改寫，確保帳號名稱唯一 |
| `presence/$uid/$sid` | 只有本人能寫自己的在線狀態 |
| `rooms/…/players/$uid` | 只有本人能寫自己那一筆 |
| `rooms/…/watchers/$uid` | 只有本人能加入／離開觀戰 |
| `rooms/…/state`、`live` | 同房玩家可讀寫（輪次、倒數、觀摩畫面需共同維護） |
| `best/$帳號` | 可寫入成績，但分數須為 0–100 的數字且需含 account 欄位 |
| `hall` | **只能新增，不能修改或刪除**（符合名人堂永久保留的設計） |
| `queue/$uid` | 只有本人能加入／退出排隊 |
| 其他所有路徑 | 一律拒絕 |

### 對接後的效果

| 資料 | 儲存路徑 |
|---|---|
| 玩家個人資料（帳號、Email、生日、頭像） | `users/{uid}` |
| 玩家帳號唯一性索引 | `accounts/{帳號}` |
| 在線工作階段（同帳號上限 3） | `presence/{uid}/{sid}` |
| 觀戰名單 | `rooms/{roomId}/watchers/{uid}` |
| 遊戲空間狀態與玩家位置 | `rooms/{roomId}/players`、`rooms/{roomId}/state` |
| 答題畫面即時分享（供同房玩家觀摩） | `rooms/{roomId}/live` |
| 玩家最佳成績 | `best/{學號姓名}` |
| 👑 侍酒大富翁名人堂（僅勝出者・永久保留） | `hall`（僅新增，不覆蓋） |
| 滿員排隊名單 | `queue/{uid}` |

### 進階：改接其他 Firebase 專案

教師後台 → ⚙️ 設定 → 展開「🛠 進階：改接其他 Firebase 專案」，貼上完整的 `firebaseConfig` JSON（需含 `databaseURL`），留白則使用內建設定。

> ⚠️ **關於安全性的誠實說明**：網頁前端的金鑰混淆只能防止「用記事本打開原始碼直接看到」，無法防止有程式基礎的人從執行中的頁面取出。
> 真正的保護來自 Firebase 端的**安全性規則**與**授權網域**設定，請務必完成上述第 3、4 點。

- **滾輪 / 雙指縮放**：放大縮小，用於檢視各格關卡名稱
- **右下角按鈕**：＋放大　－縮小　⟳旋轉　⌂重設視角
- **點擊任一格**：下方顯示該格名稱、所屬區域與學習目標

## 九、教學延伸建議

25 格 × 每格 2～3 題的規模，非常適合延伸做成：

- 實體大富翁棋盤 ＋ 25 張關卡卡（後台「題庫檢視」可直接列印）
- 每張關卡卡加上 QR Code，掃碼進入該格的 AI 語音侍酒挑戰
- 第 17、18、23、24、25 格的敘事題，可作為**桌邊服務口試**評分表

學生最後真正形成的專業思考流程：

**料理分析 → 酒款分析 → 選酒 → 搭配理由 → 顧客需求 → 服務敘事**
